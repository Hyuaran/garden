# Garden とは

Garden は、ヒュアラングループのための社内の仕組み（Garden Series）です。
バラバラのツールに散らばっていた仕事を一つにまとめ、**責任者の右腕＝「もう一人の自分（責任者2号）」**になることを目指しています。

## なぜ作るのか

- 使うツールも、見る場所も、操作も複数ある。その分だけ**うっかりミス（ヒューマンエラー）**が起きる。
- 処理の中身が同じでも、仕組みにできるところは仕組みにする。そうすると**正確になり、全体が目で見てわかる**ようになる。
- 責任者の**手を空ける**だけではない。一つ上の役職の人が、**部下の報告を待たずに**、間違いが起きやすい所や仕事の漏れにいち早く気づけるようにする。
- 新しい事業に関わるのは役職者が中心。いつもの仕事を守りながら、**ためらわず・遅れずに、全力で新しい挑戦ができる**ようにする。

## なぜ自分たちで作るのか

- 既製品を入れると「また一つツールが増えるだけ」で、散らばりがひどくなる。
- 既製品はできることが限られていて、仕事に合わせて作り込めない。だから**仕組みごと自分たちで設計する**。
- これまで FileMaker・Asana から Kintone へ乗り換えても、別のツールが増え、できることの限界に当たった。道具を替えるだけでは解決しない。だから「買う」ではなく「作る」。

## なぜ「Garden」なのか

- 仕組みは作って終わりではなく、**庭のように育てていくもの**。
- 込めた意味は3つ：**育てる／全部つながっている／見渡せる**。
- 名前の始まりは、社長が木が好きなこと。そこから「会社も根を張って、大木のようにどっしりした存在に育ってほしい。そうなるよう頑張りたい」という思いで Garden と名付けた。
- テーマは「**業務を育てる・人を育てる・だから木が育つ**」。

## たとえの全体像

- **1つの法人＝1本の木**。木が立っていられるのは、**幹＝架電（Tree）**という根幹があるから。
- 木が集まって**森（Forest）＝グループの全法人**になる。
- 庭には**小川（Rill）**が流れ、情報を巡らせる。
- 木 → 庭 → 森 と、だんだん広く見渡していく作り。

## 12のモジュール

| モジュール | 担当 | 意味 |
|---|---|---|
| Soil（土） | データの基盤 | 森を育てる肥沃な土。営業リスト・コール履歴など大量のデータを蓄える、すべての養分の源 |
| Root（根） | 組織台帳 | 強く、しなやかな組織をつくる。すべての事業の土台 |
| Seed（種） | 新事業 | まだ蒔かれていない種。新しい事業・商材・これからの業務 |
| Sprout（双葉） | 採用 | これから芽吹く双葉。求人・面接・新人研修 |
| Tree（幹） | 架電 | 木の幹のように仕事を支える。架電・コール履歴・KPI |
| Leaf（葉） | 個別アプリ | 商材×商流ごとの葉。光コラボ・新電力・クレジット・法人携帯ほか |
| Bud（蕾） | 経理・収支 | これから花開く蕾。明細・振込・損益・給与 |
| Bloom（花） | 案件・KPI | 仕事全体の健康状態を花のように咲かせる。日報・KPI・経営ダッシュボード |
| Fruit（実） | 法人の実体情報 | 実った成果。法人番号・登記・許認可・Pマーク |
| Forest（森） | 全法人の決算 | 森のように全法人を見渡す。グループ全社の決算と経営の見える化 |
| Rill（小川） | メッセージ | 情報を運ぶ川。社内メッセージと通知を、すべてのモジュールに届ける |
| Calendar（暦） | 予定 | 日々の流れを整える暦。営業予定・シフト・スケジュール |

System（社内システム）は、入社手続き・届出・マニュアルなど、全員が使う社内の窓口です。

## 作るときの約束（ぶらさないこと）

- **少しのストレスもなく、便利になる**こと。今使っているものより少しでも使いにくければ、人は使うのをためらう。押したらすぐ反応する、待たせない。
- **画面の言葉は、読む人が次にすることを書く**。開発の言葉は出さない。
- **見た目は社長スタイルにそろえる**（ゴシック・明るい灰色の背景・濃紺とティール）。どの画面も同じ型で、迷わない。
- **見られる人・書ける人をはっきり分ける**。閲覧の範囲を広げても、書き込みの権限は広げない。
- **作ったら、使い方の資料（マニュアル）も同じ日にそろえる**。
