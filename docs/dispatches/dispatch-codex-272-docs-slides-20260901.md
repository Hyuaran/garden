　│ 資料を読む →      │ │ 動画を見る →     │ │ スライドを見る →  │

## 3. 決まりごと

- **絵文字を使わない**。アイコンは既存と同じ SVG の線画
- **ライト／ダークのどちらでも読めること**。色は既存の CSS 変数を使う
- 画像は `next/image` を使わず、動画のポスター画像と同じ `img` の書き方にする
  （非公開Storageの期限付きURLのため。`referrerPolicy="no-referrer"` を付ける）
- **`loading="lazy"` を付けない**。投影中に絵が出ないと困るため
- 画像の縦横比は 16:9。横幅いっぱいに出し、**比は変えない**
- 画面の文言に開発者用語（deck・slide・signed URL など）を出さない
