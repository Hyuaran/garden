## 0. 何をしたいのか（業務の言葉で）

Wチェックまでは **ヒュアラン** の経費として扱っていたものを、
仕訳を立てる段になって **ARATA** に付け替えることがある。

- **税理士へ渡す弥生CSVは、付け替えた後の法人（仕分け法人名）で分けて出す**
- ただし社内には **「元はヒュアランだったものが ARATA になった」という記録を残す**必要がある

いまの Garden は法人を1つしか持っていないため、**付け替えると元が分からなくなる**。
そこで「元の法人」と「仕分けの法人」を**別々に持つ**ようにする。

FileMaker台帳の22列に **法人名** と **仕分け法人名** が別々にあるのは、この運用のため
（実物にも `法人名=ARATA / 仕分け法人名=ヒュアラン` のように違う値が入っている）。

## 1. 変えたい流れ

```
承認待ち → 完了待ち（Wチェック）→ 仕訳化
                                    ├ ① 対象を選ぶ
                                    ├ ② 仕分け日・仕分け法人名・決算区分を入力する
                                    └ ③ 入力済みのものから、法人を選んで弥生CSVを書き出す
```

- ②を入れていないものは、③で書き出せない
- 台帳形式Excel（Codex-196）は今までどおり出せる。**②で入れた値がそのまま20〜22列目に入る**

---

## 2. データの持ち方

`bud_expense_requests` に次を足す（migrationのSQLを置くところまで。**本番適用はしない**）。

| 列 | 内容 |
|---|---|
| `booking_date` | **仕分け日**（日付） |
| `booking_corp_id` | **仕分け法人名**（`bud_corporations` を参照） |
| `booking_set_at` / `booking_set_by` | いつ・誰が入力したか |

- 既存の `corp_id`（＝**元の法人名**）は**そのまま残す。上書きしない。**
- 既存の `fiscal_period`（**決算区分**）を使う。いまは空なので、ここで初めて値が入る
- **入力済みかどうかは `booking_date` が入っているかで判断する。`status` は増やさない・意味を変えない**
- RLSは同じテーブルの既存方針に合わせる

## 3. 画面（仕訳化タブ）

### 3-1. 入力する
- 対象を選んだ状態で **「仕分け情報を入力」** ボタン
- まとめて入力する（選んだ全件に同じ値を入れる）
  - **仕分け日**：日付を選ぶ（入力した日ではなく、指定した日。月末などを入れる想定）
  - **仕分け法人名**：法人を選ぶ。**初期値は元の法人名**
  - **決算区分**：**自動で計算した値を最初から入れておき、直せるようにする**
    - 計算は台帳形式Excel（Codex-196）と**同じ計算を使い回す**こと（`fiscal-period.ts`）
    - レシート日付と法人マスタ（設立日・決算月）から第N期を出す
    - **どの法人で数えるかは「仕分け法人名」**（付け替えたら、付け替え先の期で数える）
    - 選んだ中で期が混ざる場合は、**1件ごとに自動計算した値を入れる**（まとめて同じ値にしない）
- 入力し直しもできる（同じ操作で上書き）

### 3-1-2. 仕分け法人名の付け替え（★東海林さん指定・2026-08-24）
- **一覧の行の上で、仕分け法人名を直接選び直せる**ようにする（行ごとの選択欄）
- **選んだものをまとめて変える**こともできる（人ひとり分をまとめて付け替える用）
- **すぐ反映すること。**「変更 → 確認 → 確定」のように一度止めない。
  押した瞬間に画面が変わり、保存も走る（**楽観更新**。保存に失敗したら元に戻して知らせる）
- 元に戻すのも同じ操作（選び直すだけ）
- **付け替えられるのは全権管理者だけ。**それ以外の人には選択欄を出さず、表示だけにする
  （経理担当でも付け替えできない。仕分け日・決算区分の入力は今までどおり経理担当以上でよい）

### 3-2. 一覧の見え方
- 一覧に **仕分け日／仕分け法人名／決算区分** を出す
- **付け替えたものは、元の法人名も分かるようにする**
  例：`ヒュアラン → ARATA`
- **未入力のものが一目で分かるようにする**（入力しないと書き出せないため）
- 人ごとのまとまり・選択額の表示（Codex-197〜199）は**そのまま維持**

### 3-3. 書き出し
- **弥生CSV**
  - **仕分け法人名**で法人を1つ選んでから書き出す（いままでは元の法人名で選んでいた）
  - **仕分け情報が入力済みのものだけ**が対象。未入力は対象外（選べないようにする）
  - 書き出したら仕訳済みにする動きは今までどおり
- **台帳形式Excel**（Codex-196）
  - 20列目「仕分け日」＝`booking_date`
  - 21列目「仕分け法人名」＝`booking_corp_id` の略称
  - 22列目「決算区分」＝`fiscal_period`
  - **3列目「法人名」は元の法人名（`corp_id`）のまま。**ここが違う値になることで、社内向けの記録になる
  - 未入力のものは、この3列を空欄にする（エラーにしない）
  - **状態を変えない読み取り専用のまま**

---

## 4. 社内向けの記録

**「元はヒュアランだったが ARATA になった」が後から追えること**が要件。

- 台帳形式Excelに **法人名（元）** と **仕分け法人名（後）** の両方が並ぶので、これが記録になる
- あわせて、**いつ・誰が入力したか**（`booking_set_at` / `booking_set_by`）を残す
- 既存の監査ログの仕組みがあれば、それに合わせて記録すること（**新しい仕組みを作らない**）

---

## 5. 変えないこと

- 承認待ち／完了待ちタブ
- `status` の値・意味・遷移
- 人ごとのまとまり／選択額／税抜の併記（Codex-197〜199）
- 台帳形式Excelが**状態を変えない**こと
- 経理ID・領収書Noは空欄のまま
- 新しいライブラリを増やさない

---

## 6. テスト

- 仕分け情報を入力すると、3つの値が保存されること。`corp_id`（元の法人）が**書き換わらない**こと
- 決算区分の初期値が、**仕分け法人名**の設立日・決算月から計算されること
  （付け替え前と付け替え後で期が変わる場合、付け替え後の期になること）
- 期が混ざる選択で、1件ごとに正しい期が入ること
- 未入力のものが弥生CSVの対象にならないこと
- 弥生CSVが**仕分け法人名**で絞られること（元の法人名では絞られないこと）
- 台帳形式Excelの3列目が元の法人名、21列目が仕分け法人名になること
- 台帳形式Excelが未入力の3列を空欄にし、エラーにならないこと
- 台帳形式Excelが**状態を変えない**こと（回帰）
- 入力し直しで上書きできること
- 一覧で `ヒュアラン → ARATA` のように付け替えが見えること
- **文字が幅からはみ出さないこと**
