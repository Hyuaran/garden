## 目的
東海林さんの依頼：右上の虫眼鏡で **Garden の画面で人が入力する欄（入力欄）は全部探せる** ようにしたい。金額は「1000」でも「1,000」でも当たるように。
取り込んだリスト・通話の履歴・同期の記録など、人が入力しない表は対象外。
作る前に、どの画面のどの入力欄がどの表のどの列に保存されるかを全部洗い出す。

## やること
1. `src/app` の全モジュール（system・root・bud・rill・sprout・leaf・tree・bloom・forest・my・m・p など）で、人が入力して保存する画面（フォーム・小窓・表の編集）を探す。保存先の API（`src/app/api/**`）・サーバー処理・Supabase の insert／update／upsert／rpc までたどり、**保存先の表と列**を特定する。
2. 入力欄ごとに次をまとめる：
   - モジュール／画面の名前（サイドバー・タブの言葉）／画面の URL
   - 入力欄の見出し（画面に出ている言葉）／種類（文字・数字・金額・日付・選ぶ欄・ファイル）
   - 保存先の表.列
   - 見られる人（その画面の権限。`src/lib/auth/permission-registry.ts` の key と役職。行ごとに見える人が決まっているもの〈本人だけ・自分のチームだけなど〉はその決まり）
   - **秘密の欄**か（マイナンバー・口座番号・パスワード・トークン・API の鍵・暗号化して保存している欄）→ 秘密は「探さない」と印
   - 結果を押したときに開く先（その画面の URL＋その行を開く方法。例：`/root/employees` で行の小窓）
3. 表ごとの行数（`pg_stat_user_tables` の目安でよい。DB は .env.local の DATABASE_URL で**読むだけ**）。
