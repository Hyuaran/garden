## 0. 何を作るか

## 2. 計算のルール（Excel の式から起こした）

| 行 | 項目 | 式（チームごと） |
|---|---|---|
| 7 | 達成率 | 着地P ÷ 目標P |
| 8 | 効率 | 着地P ÷ 稼働時間 |
| 12 | P達成金 | 達成金合計 ÷ 2 |
| 13 | P達成支給額 | 着地P ≧ 目標P なら P達成金、そうでなければ 0 |
| 15 | チーム勝利支給額 | 自チームの達成率 ≧ 相手チームの達成率 なら チーム勝利金、そうでなければ 0（両チーム同率なら両方に支給） |
| 16 | 目標P超え | ROUNDDOWN(（着地P − 目標P）× 1,000, −3) ÷ 2（着地P が目標P 以下なら 0。千円未満切り捨てのあと 2 で割る） |
| 17 | ●P達成金 | Excel に式が無く 0。Garden も 0 で持つ（欄は出す） |
| 18 | 合計インセン | P達成支給額 ＋ チーム勝利支給額 ＋ 目標P超え ＋ ●P達成金 |
| 11 | 個人P比率 | Excel は空欄。Garden は 個人P ÷ 着地P を出す（表示だけ。golden の比較対象にしない） |
| C16〜G16 | テレマ全体：稼働時間・時間効率・目標P・達成金合計・1人 | 稼働時間＝全体の着地予想h、時間効率＝目標P ÷ 稼働時間、1人＝達成金合計 ÷ 2 |

- 目標P・達成金合計・チーム勝利金が未入力なら null 扱い（計算結果も null。0 と混同しない）
- 例（単体テストに入れる）：目標P 300・達成金合計 192,000・チーム勝利金 50,000。宮永：着地P 320・稼働時間 971.5 → 達成率 1.0667、P達成支給額 96,000、目標P超え ROUNDDOWN(20×1000,−3)/2＝10,000。小泉：着地P 280 → 達成率 0.9333、P達成支給額 0、目標P超え 0。チーム勝利支給額は宮永 50,000・小泉 0。合計インセン 宮永 156,000（96,000＋50,000＋10,000）・小泉 0（作成時に 106,000 と誤記していたのを Codex が指摘。式どおり 156,000 が正）

### 既知の差分（Excel の癖。Garden は正しい値で進める＝管理表シートのときの東海林さん決定と同じ）
1. Excel の小泉列（K4・K6）は式が宮永列（アポラン E9・E5）を参照している（コピーの直し忘れ）。Garden は小泉チームの値（アポラン F9・F5）を使う。golden の期待値は 小泉の 稼働時間 968.5・着地P 87.0 と、それに連動する達成率・効率に補正する
