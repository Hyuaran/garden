## 0. 何を作るか

今は手入力している **管理表の日別・チーム別の稼働時間（I／AF／BC 列）** と、**実績管理の人ごとの 稼働時間・稼働日数・着地予想h** を、KOT から書き出した日別 CSV を管理表ポータルにアップロードするだけで自動で入れる。あわせて、シフトと打刻の差（遅刻・早退・予定なしの出勤・予定ありの欠勤）を一覧にして、デイリーチェックで指摘できるようにする。
これは「アルバイトが Garden で打刻を始めるまでのつなぎ」。将来は Garden の打刻（system_attendance_punches）とシフト管理から同じ値を出す（今回は作らない。取り込み口の中の計算部品は打刻に差し替えられる形にする）。現場には出さない。東海林さんが並行運用する。

## 1. 入力（KOT の CSV）

- KOT の「エクスポート／インポート → 日別データ[CSV]」で、レイアウト **「Garden管理表ポータル（日）」** を選んで出したファイル。文字コード cp932（Shift_JIS）、1 行目が項目名、全項目「"」囲みのことも囲みなしのこともある
- 項目（この順）：従業員コード・雇用区分・名前・日時（曜日なし）・勤務日種別・パターン名・出勤予定時刻(時刻のみ)・退勤予定時刻(時刻のみ)・出勤打刻(丸め)(時刻のみ)・退勤打刻(丸め)(時刻のみ)・出勤時刻(時刻のみ)・退勤時刻(時刻のみ)・休憩時間・労働予定時間・労働合計時間・所定時間・遅刻時間・早退時間・労働時間予実差異
- 時間は **10 進**。区切りが「.」（7.06）でも「:」（7:06）でも同じ意味＝7.06 時間（「7:06」は 7 時間 6 分ではない）。空欄は 0
- 日時は `2026/08/01`。名前は半角スペース区切り（「宮永 ひかり」）。人設定の kot_name と突き合わせる（全角／半角スペースの違いは吸収）
- パターン名：シフトの文字（「14-21」「10-21」「シフト( 12:00 - 21:00 )」）か、休みの種類（「定休」「公休」「欠勤」「有給」「退職」）
- 項目名の並びが違う・必須項目（名前・日時・労働予定時間・労働合計時間・パターン名）が無いときは、取り込まずに「KOT のレイアウト『Garden管理表ポータル（日）』で出したファイルを選んでください」と出す

## 2. 計算のルール

### 2-1. 管理表の日別・チーム別の稼働時間（hoursByTeamByDate）
- **予定ベース**（東海林さん決定 2026-09-07）：日ごと・チームごとに **労働予定時間の合計**。8 月の Excel の手入力と 81 マス中 72 が一致する（残りは入力後にシフトが変わったもの）
- チーム＝人設定（system_kanri_person）の department（宮永チーム／小泉チーム／石原チーム）。リーダー（employment_kind 社員）も含む。**派遣は既定で入れない**が、「今月の設定」の **『チーム時間に入れる派遣』**（名前の一覧・既定＝梶野 恵園）にある人は入れる（リーダー確認中のため設定で切り替えられるようにする）
- 切り替え：「予定」「実績（労働合計時間）」を今月の設定で選べる。既定は「予定」
- 取り込んだら hoursByTeamByDate を **上書き**して inputs に保存する（手入力で直した値は次の取り込みで上書きされる。画面にそう書く）。取り込み前に手入力があるマスは「上書きしました」の一覧に出す

### 2-2. 実績管理の人ごとの月の値（personMonthly）
- 稼働時間（workHours）＝その人の **労働合計時間の合計**（実績）
- 稼働日数（workDays）＝出勤打刻がある日の数
- 着地予想h（landingHours）＝**取り込んだ CSV の範囲での 実績＋範囲より後の日の 労働予定時間**。月末の CSV なら実績と同じ。月の途中なら「実績＋残りの予定」
- 取り込んだら personMonthly の 3 項目を上書きして保存（fieldPoints は触らない）。人設定に無い名前は「台帳に無い」の一覧に出して無視する。CSV に無い人（人設定にはいる）は値を変えない
- 8 月の実績管理の H（稼働時間）と一致しない人が出るはず（Excel は KOT 月別の所定＋残業）。合わない人と差を 9 章に列挙する（ここは golden にしない。実績の定義が違うため）

### 2-3. 打刻の差の指摘（デイリーチェック用）
- 1 人・1 日ごとに次を判定し、一覧にする（管理表タブの「勤怠の確認」に出す。件数だけを上に、押すと明細）
  - 遅刻：遅刻時間 > 0（KOT の計算値）。あわせて 出勤打刻(丸め) が 出勤予定時刻 より後なら分差を出す
  - 早退：早退時間 > 0、または 退勤打刻(丸め) が 退勤予定時刻 より前
  - 予定なしに出勤：パターン名が休み（定休・公休・欠勤・有給・退職）または空なのに 出勤打刻 がある
  - 予定ありで打刻なし：パターン名がシフトなのに 出勤打刻 が空（その日が取り込み範囲の最終日以前のときだけ）
- 注意書きを画面に出す：「KOT の打刻は編集後の時刻です。数分の遅れは編集で消えていることがあります」（設計書 4 章の実測）

### 2-4. 保存
- CSV の行は run に紐づけて **system_kanri_source_row（source='kot_daily'、record_id＝従業員コード＋日付）** に payload（項目名→値）で保存する（表は増やさない。同じ run に再取り込みしたら置き換え）
- 取り込み結果の要約（期間・人数・行数・台帳に無い名前・上書きしたマス）は run の summary に足す
