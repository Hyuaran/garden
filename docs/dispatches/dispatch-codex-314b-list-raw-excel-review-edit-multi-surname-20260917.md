## 0. 何を仕上げるか（東海林さん 2026-09-17 GO）

Codex-314 で残った 4 つ。

1. **要確認をその場で直す**：チェック結果の要確認一覧で、氏名（姓／名）・電話番号・郵便番号・リスト名を画面で直し、［再チェック］で直した値を含めてもう一度サーバに通す。直した行は要確認から消える（直っていなければ残る）
2. **複数ファイルの同時アップロード**：画面のファイル選択とドラッグ＆ドロップで複数（光回線とクレカの混在も可）。API は対応済み
3. **よくある姓の一覧で姓名を自動で分ける**：区切りの無い氏名（7/25 の実データで 413/5,079＝8%）を、日本の姓の上位一覧（約 1,500 件・`src/app/api/soil/list/_lib/raw-excel/surnames.ts` に配列で持つ。出典を注記）で前方一致し、**最長一致の姓 1 つに決まれば**姓・名に分ける。決まらない（候補なし・2 文字の姓と 3 文字の姓の両方が当たる等）ときだけ「氏名の区切りなし」で要確認。分けたものは要確認にしない
4. **.xls**：exceljs は .xls を読めないので、「.xlsx で保存し直してから上げてください」の案内は今のまま。ただしテンプレートの書き方シートにも同じ注意を足す

## 2. 姓名分割の規則（`normalize.ts` の `normalizeName`）

1. 姓・名が両方入っていればそのまま
2. 片方だけで空白（半角・全角）があれば空白で分ける
3. 空白が無ければ **姓の一覧で前方一致**。最長一致が 1 つに決まり、残り（名）が 1 文字以上なら分ける。決まらなければ姓に全部＋要確認「氏名の区切りなし」
4. 姓の一覧は `surnames.ts`（上位約 1,500・出典の注記・重複なし・長い順に照合）。テストに「佐藤太郎→佐藤／太郎」「長谷川一郎→長谷川／一郎（長谷 ではなく最長）」「小林→ 名が残らないので要確認」を入れる
