# Codex-447c：銀行口座マスタの一覧を幅に収める・変えられない欄を見分けやすく（2026-10-27）

## 前提
Codex-447・447b の続き（`docs/dispatches/dispatch-codex-447b-root-bank-accounts-polish-20261027.md`）。中身（取得・保存・入力チェック・送る列）は変えない。対象は `src/app/root/bank-accounts/page.tsx`・`page.module.css`・`page.test.tsx` だけ。

## Claude が画面で測った結果
- 一覧の表の幅が 1560px（法人 202・銀行 202・支店 180・種別 67・口座番号 112・補助科目名 404・取り込み 112・状態 90・操作 191）。1440px の画面でも右がはみ出し、1024px では見える幅 623px に対して半分以上が隠れる。スマホ（375px）は法人と銀行の 2 列しか見えない。
- 修正の小窓：ダーク表示で、変えられない 3 つ（法人・銀行・口座番号）がほかの欄と同じ見た目で見分けにくい。

## 直すこと
1. **列をまとめて細くする**（1440px 以上で横にはみ出さない。1024px でもはみ出しを最小に）
   - 「口座」1 列に 2 段：上段 銀行名、下段 支店名 支店コード（小さめ・薄い色）。
   - 「口座番号」1 列に：種別 口座番号（例「普通 3026280」・折り返さない・`CLARITY_MASK` はそのまま）。
   - 法人は内容に合わせた幅（ほかの列と同じ左右の余白をとる。今は左端に文字がくっついて見える）。
   - 補助科目名は残りの幅を使い、区切りのよい所で折り返す（今の折り返し方は良い）。
   - 明細の取り込み・状態・操作は内容に合わせた最小の幅。
2. **760px 以下は表をやめて 1 口座 1 枚のカード**：1 行目 法人・状態、2 行目 銀行 支店、3 行目 種別 口座番号、4 行目 補助科目名（小さめ）、右下に 編集・停止／再開。カードを押すと編集（書ける人だけ）。横に動かさずに全部見えること。
3. **変えられない欄**：法人・銀行・口座番号は、ライト・ダークどちらでも一目で「変えられない」と分かる見た目に（背景を一段沈める・文字を薄く・カーソル not-allowed・選択肢の矢印を消す）。色は `colors`／`var(--root-…)` を使う。
4. テスト：カード表示（760px 以下）でも 12 口座が出て編集できること、を足す。
