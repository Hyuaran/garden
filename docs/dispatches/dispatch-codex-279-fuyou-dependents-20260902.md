3つをまとめて行う。

1. 入社手続きで**世帯主の氏名と続柄**を聞く（列は追加ずみ）
2. **扶養控除申告書**に、世帯主・続柄と、扶養親族の欄（A欄・B欄）を入れる

`system_onboarding` に `householder_name text` / `householder_relation text`。

## 1. 入社手続きで世帯主を聞く

「ご家族」の段の**いちばん上**に足す。扶養家族の一覧より前。

```
　ご家族
　　世帯主の氏名        [ 吉田　陽菜                    ]
　　世帯主との続柄       [ 本人 ▼ ]
　　　　　　　　　　　　 ご本人が世帯主なら「本人」を選んでください

　　扶養家族　　　　　　 [ もう1人足す ]
　　　（以下、いまの扶養家族の入力）
```

- 項目名は **「世帯主の氏名」**「**世帯主との続柄**」
- 続柄は選ぶ形。選択肢は **本人 / 夫 / 妻 / 父 / 母 / 祖父 / 祖母 / 子 / 兄弟姉妹 / その他**
- **「本人」を選んだら、世帯主の氏名に本人の氏名を自動で入れる**（あとから直せる）
- 未入力でも提出できる（他の項目と同じ）。未入力なら「未入力の項目」に出る
- `TEXT_FIELDS` に `householder_name` と `householder_relation` を足し、
  `FIELD_LABELS` と「ご家族」の段（`STEP_FIELDS`）に入れる
- 事務の詳細画面（読むだけ）にも2つを出す

## 2. 扶養控除申告書に入れる

`src/app/system/onboarding/_lib/fuyou-pdf.server.ts` に足す。

### 2-1 世帯主

| 用紙の欄 | 中身 |
|---|---|
| `Text14` | 世帯主の氏名（文字サイズ9） |
| `Text15` | 世帯主との続柄（文字サイズ10） |

いま画面に出している注意書きから **「世帯主」を消す**
（「税務署名・市区町村名・扶養親族の欄は空欄です。手書きで足してください。」に変える）。

### 2-2 扶養親族の欄

**扶養家族の続柄で振り分ける。**

- **続柄が「配偶者」の人** → A欄（源泉控除対象配偶者）に1人だけ
- **それ以外の人で、令和8年1月1日時点で16歳以上** → B欄に上から順に最大4人
- **16歳未満（平23.1.2以後生まれ）** → 「16歳未満の扶養親族」欄に上から順に最大2人
- あふれた人は入れない。**あふれたら画面に「◯人分は用紙に入りきらないため手書きで足してください」と出す**

### A欄（配偶者・1人）

| 欄 | 中身 |
|---|---|
| `Text16` | フリガナ（文字サイズ7） |
| `Text17` | 氏名（文字サイズ9） |
| `Text18` | 個人番号（数字だけ12桁。コーム欄なので数字だけ入れる） |
| `Dropdown4` | 生年月日の元号（明/大/昭/平/令 の1文字） |
| `Text19` `Text20` `Text21` | 生年月日の 年・月・日 |
| `Text22` | 令和8年中の所得の見積額（年間収入をそのまま。数字だけ） |
| `Text23` | 住所又は居所（**本人と同じ住所**を入れる。文字サイズ8） |

**A欄には「あなたとの続柄」の欄が無い**（用紙に斜線が引いてある）。入れない。

### B欄（16歳以上・最大4人）

1人あたり10欄。**先頭の番号だけ変わり、並びは同じ。**

| 順番 | 1人目 | 2人目 | 3人目 | 4人目 | 中身 |
|---|---|---|---|---|---|
| フリガナ | `Text25` | `Text35` | `Text45` | `Text55` | 文字サイズ7 |

| あなたとの続柄 | `Text28` | `Text38` | `Text48` | `Text58` | 文字サイズ9 |
| 生年月日 元号 | `Dropdown5` | `Dropdown6` | `Dropdown7` | `Dropdown8` | 1文字 |
| 年 | `Text29` | `Text39` | `Text49` | `Text59` | |

無い欄名を触って落ちないようにすること）。`Text64`（異動月日）は入れない。

### 16歳未満の欄（最大2人）

先頭は `Text90`（1人目）と `Text99`（2人目）**の並びが確かめられていない**ため、
**この欄は今回入れない。** 画面の注意書きに「16歳未満のお子さんの欄は空欄です」と足す。

### 生年月日の和暦

本人の生年月日と同じ換算（`toWarekiDate`）を使い回す。

## 3. 入社連絡表に入れる

`src/app/system/onboarding/_lib/renrakuhyo.ts` / `.server.ts` に足す。
**扶養家族は上から順に最大4人**（用紙の欄が4人分）。

### Excelのセルと、PDFの位置

1人あたり3行（フリガナ／氏名／マイナンバー）＋続柄・生年月日・年間収入・職業。

| 欄 | 1人目 | 2人目 | 3人目 | 4人目 |
|---|---|---|---|---|
| フリガナ | `D17` | `D20` | `D23` | `D26` |
| 氏名 | `D18` | `D21` | `D24` | `D27` |
| マイナンバー | `D19` | `D22` | `D25` | `D28` |
| 続柄 | `F17` | `F20` | `F23` | `F26` |
| 生年月日 | `G17` | `G20` | `G23` | `G26` |
| 年間収入 | `H17` | `H20` | `H23` | `H26` |
| 職業・学校学年 | `I17` | `I20` | `I23` | `I26` |

- マイナンバーの行は、ひな形に `マイナンバー（　　　　　　　　　　　　　　）` と入っている。
  **その文字は残したまま、かっこの中に12桁を書く**形にする。
  Excelは `マイナンバー（ 1234-5678-9012 ）` の文字列を入れる。
- 生年月日は `2003年9月28日` の形
- 年間収入は数字にカンマ（`0` のときは `0`）

**PDFの位置は、この指示書だけでは分からない。**
Excelに値を入れたものを作り、**同じやり方（目印を入れて測る）で座標を出すのは Claude が行う。**
Codex は **Excelだけ先に実装し、PDFの扶養家族は入れないこと。**
PDFには**画面の注意書きで「扶養家族の欄はExcelのみ。PDFは空欄です」と出す。**
