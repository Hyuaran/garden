# Codex-427：入社手続き（事務）のタブを［入社予定者］［入社後の確認］［入社手続き］の 3 つに分ける（2026-10-26）

## 目的
今の「入社予定者」タブに、入社済みの人（入社後の確認が残っている人）も並んでいて分かりにくい（東海林さん）。タブを分ける。Codex-426 で直した表の幅・改行はそのまま生かす。

## 画面の絵
```
System ／ 入社手続き（事務）
[入社予定者] [入社後の確認] [入社手続き]
［入社予定者］：status が planned／hiring の人だけ（入社予定・KOT 登録待ち・名簿登録待ち・Garden 反映待ち）。［＋ 入社予定者を登録］はこのタブ。「来なかった」の人は下の「来なかった人も表示」をオンにしたときだけ出す。
［入社後の確認］：status が hired で、入社後の確認（checklist ＋入社手続き提出・公式 LINE）がそろっていない人。列＝入社日・氏名・社員番号・入社手続き・公式 LINE・雇用契約書（送った／締結済み）・秘密保持（同）・緊急連絡先（同）・FileMaker（追加済み）。チェックは今と同じく押したらすぐ保存。
   全部そろった人は消える。「完了も表示」をオンにすると見返せる（完了の人は「完了」と表示）。
［入社手続き］：今の一覧そのまま。
```
- 入社後の確認の表は、項目ごとに 1 列にして、チェックボックスと文字を離す（社長スタイルの `DataTable`・見出しは中央ぞろえ・横に長いときは固定の横スクロール）。
- 3 タブとも super_admin だけ［入社予定者］［入社後の確認］が出るのは今と同じ（責任者などは［入社手続き］だけ）。
- 「完了も表示」「来なかった人も表示」は人ごとに覚える（localStorage・try/catch）。
