# Codex-544 関電 事務入力 一覧の軽量化と表示修正

## 実装

- 事務入力は現在のタブを50件ずつ取得する。検索、列の並べ替え、絞り込み、ページ送りはDB側で行う。件数バッジはタブを開いた時に同じRPC内で集計する。明示的な更新と保存完了時にもバッジを更新する。
- 行を選択すると1回のサーバーアクションで、その案件の詳細、写メ、入金明細、変更履歴を返す。供給地点の重複は全受注から照合する。前へ／次へと Ctrl+↑↓ はページ境界を越えて選択でき、一覧の応答を待つ間は前の一覧を表示する。
- 広い画面では一覧・入力・書類の3列、1280px未満では一覧と入力の2列で書類は下段、900px未満では作業欄のタブで切り替える1列にした。表示領域が狭い場合も列を組み替える。表は固定レイアウトにし、長いお客様名の省略表示、見出し中央、縦線、交互の背景色、選択行の強調を設定した。
- 案件一覧 `/leaf/kanden` でも年度・タブ内の全受注を返していたため、フォーム受付タブを含めてサーバー側の50件ページに切り替えた。

## FileMaker の日付

- 「申込Excel送付日」を `mailed_on` に取り込む。migration 544 は既存の FileMaker 受注で郵送日が空欄のものを `app_sent_on` から補完する。旧「郵送前キャンセル」の判定から郵送済みの受注を外し、申込書受取日が空欄の郵送済み案件も入金待ちとして扱う。
- `invoice_sent_on date` は migration 537 で作成済みのため、その列を利用する。「請求Excel送付日」を事務入力の郵送日の次に置き、事務入力の一覧と案件一覧・詳細にも表示する。
- 適用ファイルは `supabase/migrations/20261120000544_leaf_kanden_invoice_sent.sql`。Garden で編集済みの行を再取込の対象から外す既存の条件を引き継ぐ。FileMaker の再取込は Claude 担当。

## Vercel 呼び出しの見積もり

- 定期呼び出しの追加は **0回／日**。初期画面、タブ・検索・絞り込み・並べ替え・ページ送りは各1回。案件選択は1回で、ページ境界を越える場合は一覧取得が別に1回。更新ボタンは一覧と再読込できる詳細の最大2回。保存は保存・一覧・詳細と、境界で必要な次ページを含めて最大4回。供給地点を有効な22桁に変更して入力が止まった時は重複照合を1回。
- 例として1日あたり画面表示20回、一覧操作50回、案件選択100回、保存20回、更新10回、供給地点の照合10回なら、上記の操作で最大 **約280回／日**。ページ境界の一覧取得は一覧操作50回に含む。

変更ファイルの改行は LF。
