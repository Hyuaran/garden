## 1. 画面の絵

事務の画面 `/system/onboarding/admin/<社員番号>` の下のほうに、囲みを1つ足す。

```
　┌ 扶養控除申告書 ────────────────────────────────┐
　│ 令和8年分の用紙に、本人が入れた内容を書き込んで、             │
　│ 経理のフォルダへ保存します。マイナンバーが入ります。            │
　│                                                    │
　│ 　[ 扶養控除申告書を作る ]                              │
　└────────────────────────────────────────┘
```

押すと、**画面の中に**確認を出す（ブラウザ標準の窓は使わない。反映ボタンと同じ形）。

```
　┌────────────────────────────────────────┐
　│ マイナンバーが入った書類を、経理のフォルダに保存します。         │
　│ よろしいですか                                        │
　│ 　[ 作って保存する ] 　[ やめる ]                         │
　└────────────────────────────────────────┘
```

保存できたら、その場に結果を出す。

```
　┌────────────────────────────────────────┐
　│ 保存しました。                                        │
　│ 【扶養控除申告書】上田基人_令和8年分_給与所得者の…pdf         │
　│ 経理部 ／ 12_扶養控除申告書 に入っています                  │
　└────────────────────────────────────────┘
```

失敗したら、その場に理由を出す（例：「保存先のフォルダに書き込めませんでした。管理者へお問い合わせください。」）。
**画面に開発者用語（Drive API・token・scope など）を出さない。**

## 2. 書き込む欄（令和8年分の用紙）

用紙の欄名は `Text1`… のように付いている。**今回書き込むのは次だけ**。

| 用紙の欄 | 中身 | 入れる値 |
|---|---|---|
| `Text3` | 給与の支払者の名称 | 所属法人の名前（`root_companies`） |
| `Text4` | 法人番号 | 所属法人の法人番号 |
| `Text5` | 給与の支払者の所在地 | 所属法人の住所 |
| `Text6` | フリガナ | `name_kana`（文字サイズ7で固定） |
| `Text7` | 氏名 | `name`（文字サイズ10で固定） |
| `Text8` | 個人番号 | `my_number`（数字だけ12桁） |
| `Dropdown1` | 生年月日の元号 | 明/大/昭/平/令 の1文字 |
| `Text11` `Text12` `Text13` | 生年月日 年・月・日 | 和暦に直した年・月・日 |
| `Text9-1` `Text9-2` | 郵便番号 前3桁／後4桁 | `postal_code` |
| `Text10` | 住所 | `address`（文字サイズ8で固定） |
| `Dropdown2` | 配偶者の有無 | 家族に続柄「配偶者」がいれば `有`、いなければ `無` |

**書き込まない欄（空欄のまま）**

- `Text1` 所轄税務署 / `Text2` 市区町村長 … Gardenに持っていない
- `Text14` 世帯主の氏名 / `Text15` あなたとの続柄 … 入社手続きで聞いていない
- A欄（配偶者）・B欄（扶養親族）・16歳未満・住民税欄 … **今回は入れない**
  （欄の細かい意味を実機1件で確かめてから次の段階で入れる）

空欄が残ることは、画面の囲みの中に一文で書いておく：
**「税務署名・市区町村名・世帯主・扶養親族の欄は空欄です。手書きで足してください。」**

### 生年月日を和暦に直す

`birth_date` は `1995-05-05` の形。次の境目で元号に直す。

| 元号 | 期間 |
|---|---|
| 令和 | 2019-05-01 以降（令和1年＝2019） |
| 平成 | 1989-01-08 〜 2019-04-30（平成1年＝1989） |
| 昭和 | 1926-12-25 〜 1989-01-07（昭和1年＝1926） |
| 大正 | 1912-07-30 〜 1926-12-24 |
| 明治 | 1912-07-29 以前 |

ドロップダウンに入れる値は **明 / 大 / 昭 / 平 / 令** の1文字。

## 3. 作り方

- PDFは **`pdf-lib` と `@pdf-lib/fontkit`** で扱う（すでに入っている）。
  契約書の `src/app/system/contracts/_lib/contract-template.server.ts` の書き方に合わせる
- 日本語は `public/fonts/NotoSansJP-Regular.ttf` を埋め込む
- **入力欄は書き込んだあと「確定」する**（`form.flatten()`）。受け取った人が中身を編集できない状態にする
- 白紙の用紙は Storage から読む（`system-docs/forms/reiwa8-fuyou.pdf`）。**Storageに書き込まない**
- 保存先は Google ドライブのフォルダ **`1O8A_4NEZFdXWDgV06MDTYCJ6qZblk6AV`**
  （`G:\マイドライブ\01_経理部\12_扶養控除申告書`）
  - 接続は既存の `src/app/api/bud/expense-drive/_lib/drive.ts` の作り（OAuthのrefresh token）をそのまま使う
  - **フォルダIDは環境変数 `GARDEN_FUYOU_DRIVE_FOLDER_ID` から読む。無ければ上のIDを既定値にする**
  - 書き込めなかったときは、画面に「保存先のフォルダに書き込めませんでした」と出す。**別のフォルダに勝手に保存しない**
- ファイル名
  ```
  【扶養控除申告書】<氏名からスペースを抜いたもの>_令和8年分_給与所得者の扶養控除等(異動)申告書.pdf
  ```
- 実行できるのは **責任者以上**（事務の画面と同じ権限。`/system/onboarding/admin` の判定をそのまま使う）
- **PDFの中身・マイナンバーをログに出さない**。保存後もサーバーにファイルを残さない
- 絵文字を使わない
