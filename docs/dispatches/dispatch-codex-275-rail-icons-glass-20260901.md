## 1. 画面の絵

### いま

```
　┌──┐   ← 背景とほぼ同じ濃さの枠に、モジュール色の線が光っている
　│ ✿ │      小さいと何の絵か分かりにくい
　└──┘
```

### これから（案3・四角版）

```
　┏━━┓   ← 板そのものがモジュール色（左上が明るく右下が濃いグラデーション）
　┃ ✿ ┃      上に白いツヤ、ふちに薄い白線、絵は白
　┗━━┛

並んだところ（レールの幅・板の大きさは今のまま 40×40、角丸12px）

```
　┌────┐
　│ ┏━┓ │ ← System（じょうろ）
　│ ┗━┛ │

　│ ┗━┛ │

　│ ┗━┛ │

### いま開いている画面の見せ方

```
　┃┏━━┓  ← 開いている：板はそのままの明るさ ＋ 板の左に白い縦バー
　┃┗━━┛
　 ┏━━┓  ← 開いていない：板全体を少し暗く（明るさ 65%）
　 ┗━━┛
```

- 白い縦バーは **幅3px・高さは板と同じ・角丸**。板の左に少し離して置く
- マウスを載せたら、暗くしていた板を**元の明るさに戻す**（今の「浮き上がる」動きは残してよい）
- 吹き出し（ツールチップ）は**今のまま**変えない

## 2. 板の描き方（1枚ぶんの作り）

56×56 の `viewBox` で描き、40×40 で表示する。

1. 角丸四角（`x=2 y=2 幅52 高さ52 角丸14`）を**斜めのグラデーション**（左上→右下）で塗る
2. その上に**白いツヤ**（上半分の楕円 `cx=28 cy=14 rx=30 ry=14`、白の透明度 0.55→0）を、四角の内側に収まるように重ねる
3. ふちに**白い線**（透明度 0.35）
4. **絵（線画）は白**。`stroke-width` は 1.5、角と端は丸める
5. いまの**光らせる効果（drop-shadow）は外す**

絵そのもの（`ModuleIcon` の中の path）は**今のものをそのまま使う**。24×24 で描かれているので、
板の中央に `translate(28,28) scale(1.45) translate(-12,-12)` で置く。

## 4. じょうろ（System）の絵を描き直す

いまの絵は線が細く、水滴が小さいため、板の上で見えにくい。**同じ形のまま、次だけ変える。**

- 線の太さを **1.5 → 1.9**
- 水滴を**少し大きく・長く**する（いまの `M20 14.4v1.4` `M17.6 15.6v1.2` を、それぞれ 2.2 と 1.8 程度の長さに）
- 全体を**気持ち大きく**（`scale(1.45)` を System だけ `1.55`）
- 形（じょうろ本体・注ぎ口・持ち手）は変えない
