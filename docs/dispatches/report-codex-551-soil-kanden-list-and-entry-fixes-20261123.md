# Codex-551 Soil 関電リスト・事務入力 実装報告

## 実装

- `20261123000551_soil_kanden_list.sql` で、Prodelight のリストを受注と別に保管する。管理番号の原文と正規化値を保持し、管理番号、お客様番号、電話3種、カナに索引を付けた。RLS の閲覧条件は関電の営業フォームまたは事務入力の閲覧権限と事務入力の公開日に連動する。書き込みは `service_role` に限定した。全体検索への登録は対象外。
- `scripts/soil-kanden-list/import-list.ts` は UTF-8 BOM 付き CSV を検証し、5,000件ずつ Supabase へ送る。ROWID で突き合わせ、既存より古い修正日の行と同一内容の行を飛ばす。同日の内容変更は反映する。保存済みの修正日が有効で入力側が無効な行は保存済みデータを保持する。適用件数を `leaf_kanden_import_runs` に記録し、確認・更新・スキップの件数を表示する。
- 事務入力は詳細の取得時に正規化した管理番号で照合し、修正日が最新の行を使う。同日なら ROWID が最大の行を使う。照合マークを ✓・！・＋ で分け、不一致の入力欄を赤系で強調した。項目・セクション・全項目の転記は入力欄に反映する。該当行がなければ「リストに無い案件」を表示する。
- 写メの「すべて」タブを追加した。分類済みの写メがあれば最初の該当タブを、未分類だけのときは「すべて」を開く。案件タブは押した時点で選択状態を変え、応答までは前の表示を薄く残す。日付帯を案件タブの直下へ移し、操作ボタンを横並びで折り返す。
- 指定の CSV 見出しには供給地点特定番号がないため、同名の任意列がある場合に限り22桁の値を保持・転記する。営業フォームでの顧客情報の自動取得は Codex-552 の範囲。

## ホスト PC での実行

事前確認は `npx tsx scripts/soil-kanden-list/import-list.ts --file "<CSVのパス>" --dry-run`。マイグレーションの適用後、本取り込みは同じコマンドから `--dry-run` を外す。既に保存済みの行は差分判定されるため、途中で失敗した場合は同じ CSV で再実行できる。
