## 東海林さんの指示
Root「銀行口座マスタ」（`src/app/root/bank-accounts/page.tsx`）の表の右端に「操作」の列（鉛筆の編集ボタン・［廃止］ボタン）がある。決まり「表の行は全体を押して小窓を開く・［変更する］の列は置かない」に合っていないので直す。同じ形の表が他にもあれば全部同じに直す。

## やること
1. **探す**：表（共通 `DataTable`・`<table>`・Root の古い表）の行の中に、その行を編集・削除・廃止・無効化するためのボタンが並んでいる所を Garden 全体で探す（`RowActionButton`・「操作」の見出し・「廃止」「無効」「停止」「復活」などのボタン）。
2. **直し方**：
   - 「操作」の列（見出しごと）を消す。
   - 行全体を押すと、今の鉛筆ボタンと同じ編集の小窓が開く（共通 `DataTable` なら `onRowClick`。自前の表なら `tr` に `onClick`・`role="button"`・`tabIndex={0}`・Enter／Space でも開く・押せる見た目＝カーソル pointer とホバー色）。
   - 削除・廃止・無効化・復活などは、**その小窓の中**へ移す（小窓の下の左側に、危ない操作の見た目＝`data-modal-action="danger"` で置く。押すと今と同じ確認が出る）。ブラウザの confirm は使わない（今使っていれば共通の小窓の確認に）。
   - 行の中で別の小窓や別の機能を開くもの（例：INNOVERA の［再生］・ファイルを開くリンク・外部へのリンク）はそのまま残す。行を押したときの動きとぶつかる場合は、そのボタンの押下で行の押下が起きないようにする（`stopPropagation`）。
   - 書き込みの権限が無い人には、今と同じく編集できない（行を押しても読むだけの小窓、または何も開かない＝今の権限の動きに合わせる）。
3. 状態の列（有効・廃止など）は残す。
