## 1. ページの途中で切れて下が空く（リストごと・従業員ごと）

### 症状
リストが54件あるとき、2ページ目に30件だけ入り、**ページの下3分の1ほどが空いたまま**次ページへ送られる。
従業員ごとも同じで、40件で区切られる。

### 原因
`src/app/system/_lib/call-metrics-pdf.tsx` の `chunks(data.employeeMetrics, 40)` /
`chunks(data.metrics, 30)` で、**入るかどうかに関係なく固定の件数でページを割っている**。
実測では1ページに **45行前後** 入る余地がある。

### 直し方
**固定件数での分割をやめ、ページに入るだけ入れて、あふれた分が自然に次ページへ流れる形にすること。**

- `@react-pdf` の `Page` は `wrap` で自動的にページを送る。表の見出し行は `fixed` にしてあるので、
  次のページでも見出しは繰り返される（いまも動いている）。
- 行の高さは、長い名前が2行に折り返されると変わる。**固定の行数を前提にしないこと。**
- 各部の見出し（「従業員ごと」「リストごと」）は、その部の**最初のページにだけ**出す。
  2ページ目以降は「（続き）」を出す形を維持してよいが、**行数を固定して作るのはやめる**こと。

**確認方法**：本日の実データ（従業員16人・リスト54件）で出したとき、
リストごとが**ページの下まで詰まっている**こと。

---

## 2. どのページも表の右に白い帯が出る

### 症状
表の右端（一番右の列の外側）に、**白い長方形が page の右余白まで伸びている**。紙面が汚れて見える。

### 原因
`styles.table` が `width: "100%"` かつ `backgroundColor: COLORS.card`（白）。
一方、列の幅の合計は A3 の本文幅より狭い（従業員ごとで約620pt／本文幅は約786pt）。
**その差の分だけ、白い背景が右にはみ出して見えている。**

### 直し方
**表の枠の幅を、列の幅の合計にそろえること。**（`width: "100%"` をやめる、等）
表の右端と、一番右の列の右端が**ぴったり一致する**こと。

- 3つの表（従業員ごと・リストごと・定義方法の各表）すべてで直すこと。
- 表を紙面の幅いっぱいに引き伸ばす必要はない。**余った分は背景（`#F4F5F7`）のままでよい。**

## 3. 表の一番上（紺色の見出し行）を全部中央揃えにする

いまは見出しが右揃えで、「社員名」だけ中央揃え。**紺色の見出しは全部中央揃えにする。**

- **PDFと画面（`/system/call-metrics`）の両方**を変えること。
- **中身（データ行）は今までどおり**：社員名・リスト名は左揃え、数字は右揃え。見出しだけ中央。
- 対象は3つのタブすべての表（従業員ごと・リストごと・定義方法）。
- 画面側は `src/app/system/call-metrics/call-metrics.module.css` の
  `.main th` まわり（`text-align: right` と `.main th:first-child { text-align: left }`）を直す。
  **`td` の揃えは変えないこと。**

※ Codex-189 で「社員名の見出しだけ中央」としたが、**今回それを「見出しは全部中央」に変える**。
