## 1. 写し方の直し（`roster-push.server.ts`）
- PUT の前に Kintone の今のレコードを 1 件 GET し（`/k/v1/record.json?app&id`）、**項目ごとに「同じとみなす」なら送らない**。PUT に入れるのは違う項目だけ。違う項目が 0 なら PUT しない（queue は done）。
- 同じとみなす決まり（関数 `sameRosterValue(code, kintoneValue, gardenValue)`・テストつき）：
  - **Garden の値が空（null・空文字・空白だけ）なら送らない**（Kintone の値を残す）。Garden で消したいときは今は考えない。
  - 文字の比べは、前後の空白（半角・全角）を外し、全角英数を半角にして比べる。
  - 電話（連絡先・連絡先_1〜3）・郵便番号・口座番号・金融機関コード・支店コードは、数字だけにして比べる（同じなら送らない。違うときは Kintone の今の形に合わせる：今の値にハイフンがあれば Garden の数字を同じ区切り位置で、無ければ数字だけ）。金融機関コード・支店コードは先頭の 0 を落とさない。
  - 住所の細目（郵便番号・都道府県・市町村・町域・建物名・部屋番号・住所）は、**Garden の最新の住所の履歴が Root の編集（source='admin'）で入れたものときだけ送る**。それ以外（名簿・届出・照合から来た住所）は送らない。

- 送らない項目を足す：`打刻ID`（鍵として使うだけ）・`メールアドレス` が `@garden.internal` で終わるとき・`従業員名_姓`／`従業員名_名`（`従業員名_姓名` が違うときだけ分けて送る）。
