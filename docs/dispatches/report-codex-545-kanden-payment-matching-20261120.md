# Codex-545 関電 入金明細と受注の照合 実装報告（2026-11-20）

## 実装

- 明細を動力・ガス・電灯に分類し、対応する受注のお客様番号と門標を数字だけにそろえて照合する。門標の候補が複数なら、枝番込みの管理番号が一致する候補を優先する。
- 門標で候補が見つからなければ、明細と受注の管理番号原文から作った枝番込みのキーと種類で照合する。照合用キーは保存用の管理番号とは別に計算する。
- 候補が複数残る場合は、送信日以前の最新の受注日が一意なら採用する。日付が同じなどで決められない場合は order_id を空にし、match_note に理由を記録する。
- dry-run では門標・管理番号それぞれの一致行数と、受注日で絞った行数を表示する。受注日の件数は門標または管理番号で一致した行の内数。
