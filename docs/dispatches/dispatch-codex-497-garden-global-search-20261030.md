## 作るもの
1. **虫眼鏡のボタン**：右上のボタン列のベルの左に、線画の虫眼鏡アイコン（絵文字は使わない）。`GardenHeaderActions`・`src/app/_components/layout/GardenShell/ModuleShell.tsx`・`BudShachoShell`・`RillShachoShell`・`MyShell` の全部（スマホの上の帯も）。ツールチップ「Garden 全体を検索（Ctrl+K）」。
2. **検索の小窓**：共通 Modal（size="lg"）。開くと入力欄にフォーカス。Ctrl+K（Mac は Cmd+K）でどの画面からでも開く。入力は 250ms 待ってから検索（打つたびに送らない）。↑↓ で選ぶ・Enter で開く・Esc で閉じる。結果は種類ごとの見出し（「画面」「従業員」「経費」…＝その表を使う画面の言葉）。各行＝主な文字（氏名・題名など）＋当たった欄の見出しと値の一部（当たった文字を太字）＋右端にモジュール名。0 件は「見つかりませんでした」。読み込み中は小さなくるくる（loading-style）。
3. **検索の API**：`GET /api/search?q=...`（ログイン必須）。
   - **権限**：その人が見られる画面（`src/lib/auth/permission-registry.ts`・閲覧権限の歯車の設定 `view-permission.server`）のデータだけを探す。行ごとに見える人が決まっている表（一覧の「行ごとに権限が決まる表」の節）は、**その画面が使っているのと同じ決まりで絞る**（本人の client で RLS が効く表は本人の client で読む。画面が admin client＋サーバー側の判定で読んでいる表は同じ判定を通す）。同じ決まりにできない表は検索に入れず、報告に書く。
   - **当たり方**：全角・半角と大文字・小文字の違いは無視（NFKC）。**数字はカンマを無視して比べる**（「1000」「1,000」「１，０００」が「1000」「1,000」に当たる。数値の列は文字にして比べる・金額の文字列の列はカンマを外して比べる）。電話番号の列はハイフンも無視する。日付は「2026-11-02」「2026/11/02」のどちらでも当たる。
   - 1 文字から探せる（数字だけ・英字だけは 2 文字から）。
   - 種類ごとに最大 5 件（「さらに表示」で 20 件まで）。全体で 1 秒以内（目標 0.5 秒）。並びは「完全一致→前方一致→部分一致」、同じなら新しい順。
   - **秘密の 16 欄は、探す対象にも、結果の表示にも含めない**（列を select しない）。
   - 検索した文字は監査ログ等に残さない（個人情報が入るため）。
   - 定期処理（cron）・取り直しは足さない。
4. **画面・タブも探せる**：サイドバーのメニュー・タブの名前（全モジュール・見られるものだけ）。結果の種類「画面」。マニュアルの題名も「マニュアル」として出す（マニュアルの見られる範囲に合わせる）。
5. **押したときの開き先**：一覧の「結果の開き先」の画面へ移る。その画面の検索窓（右上の置き場・Codex-495）に**探した文字を入れた状態**で開き、その行が絞り込まれて見えるようにする（URL の `?q=` を共通の DataTable が最初の検索文字として読む。行の小窓を自動で開けるところ〈Root 従業員の `?open=` など〉はあれば使う。無理に全画面へ足さない）。
