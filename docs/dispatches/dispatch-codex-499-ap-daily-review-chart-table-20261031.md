## やること
1. **区分**：グラフ・表の「トス／獲得」の名前は、直近の日報の `kind` が `toss` なら「トス」、`closer` なら「獲得」。混ざっている人は「トス・獲得」とし、値は各日の `count`。
2. **並び**：グラフ・表とも `recent` を**古い順**（左＝古い）。表の初期の並べ替えは日付の新しい順。日報が無い日は出さない（＝出勤がある日だけ）。
3. **グラフ**（`chart.js`＋`react-chartjs-2` はもう入っている。例：`src/app/forest/_components/MacroChart.tsx`）
   - 折れ線 5 本・1 枚。左の目盛り＝総コール・留守。右の目盛り＝見込み・トス／獲得・コイン作成数（`yAxisID`）。両方 0 始まり・整数目盛り。軸の題「件」。
   - 横軸のラベルは `10/28` の形（月/日）。ツールチップは「2026-10-28　総コール 195件」の形で、その日の 5 本を全部出す（`mode: 'index'`）。
   - 凡例は下。押すと線を消す／出す（chart.js の標準）。
   - 色：5 本がライト・ダークの両方で見分けられること。社長スタイルの色（濃紺 `#10233F`・ティール `#0EA5A0`）を軸に、他 3 色は濃さ・色相の違う落ち着いた色。**ダークでは濃紺が背景に沈むので別の色に切り替える**（`prefers-color-scheme` と Garden の明暗切り替え＝`html[data-theme]` の両方を見て色を決める。既存の書き方があればそれに合わせる）。軸の文字・目盛り線もダークで読める色に。
   - 高さはパソコン 360px 前後・スマホ 260px 前後。幅は本文いっぱい（上限なし）。
   - 日報が 1 件だけのときは点 1 つでよい（線が引けないだけ）。0 件は今と同じ「まだありません」。
4. **表**（共通の `src/app/system/_components/DataTable/DataTable.tsx`。自前の表は作らない）
   - 列：日付（`2026-10-28`）・時間（`14:00～21:00`）・稼働時間（`7.0時間`）・総コール・留守・見込み・トス／獲得・コイン作成数・有効率・留守率・見込み率・トス率／獲得率。クローザーの日があれば「効率」（`efficiency` 小数 2 桁）も。
   - 率：有効率＝保存されている `effective_rate`（今の日報と同じ）。留守率＝留守÷総コール、見込み率＝見込み÷総コール、トス率／獲得率＝トス／獲得÷総コール。小数 1 桁の %。総コール 0 の日は「—」。
   - 合計の行（DataTable の `summary`）：件数と稼働時間は足し算。**率は合計の件数から計算し直す**（有効率の合計は「各日の有効率×総コール」の合計÷総コール合計）。効率は出さない（「—」）。
   - 数字は右、日付・時間は中央、見出しは中央（DataTable の決まりどおり）。検索窓の薄い字（`searchPlaceholder`）は「日付で探す」。
   - 行全体を押すと小窓（共通 `src/app/system/_components/Modal/Modal.tsx`・`size="md"`）。
5. **小窓の中身**（題＝「2026-10-28 の日報」）：区分・時間・稼働時間・総コール・留守・見込み・有効率・トス（または本日獲得・現状合計・効率）・コイン 5 つ（コイン作成数・誘導約束・誘導中・明細確認依頼・トータルコイン。空なら「記録なし」）・反省点・改善点（改行そのまま）。読むだけ（直す・送るはない）。下に［閉じる］。
6. **グラフ⇄表の切り替え**：右上のボタン列の `HeaderViewToggle`（例：`src/app/system/sites/SitesHubClient.tsx` 392 行の書き方）にボタン 1 つ。グラフのときは表のアイコン・`aria-label="表で見る"`、表のときはグラフのアイコン・`aria-label="グラフで見る"`。アイコンは SVG の線画（絵文字禁止）。最初はグラフ。選んだ方は `localStorage`（キー `garden.ap-daily-review.view`・try/catch で囲む）に覚える。**AP日報タブ（入力）にはボタンを出さない**。
