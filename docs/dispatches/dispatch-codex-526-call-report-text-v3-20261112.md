## 決まり

### 【アウトテレマ】（今の【本日】を名前を変えて直す）

- 1 行目：`従業員N名／Hｈ／総コールX回`
- **H（稼働時間）＝ KING OF TIME の当日実績の合計。テレマの人だけ**：Root の `current_team` が「宮永チーム」「小泉チーム」「石原チーム」「新人チーム」の人（チームリーダーの宮永・小泉・石原を含む）。**上田は除く**（チームが無い人は入らない）。時間は小数 1 桁を四捨五入して整数（109ｈ）
- N（従業員）も同じテレマの人のうち、当日コールがある人の数
- 平均コール数/ｈ の分母も H にそろえる
- 受注数・受注率・前確OK率は今のまま

### 当日獲得ランキング1位

- クローザー：当日の受注数（獲得）が一番多い人。**前確OK に至っていなくても受注が上がっていれば数える**
- トス：当日のトス数が一番多い人。**受注に至っていなくてもトスが上がっていれば数える**
- 同じ数の人が複数いれば全員を「・」でつなぐ（例：`2件 南薗さん・宮永さん`）
- **0 件なら、その行を出さない**。両方 0 なら見出し「当日獲得ランキング1位」も出さない
- 名前は姓だけ＋「さん」

### 【テレマ全体】（ポイント）

- 対象：Kintone 顧客一覧（app10）で**受注日が当日**の案件。事業名「自社」「アライアンス」
- 獲得方法は `resolveChannel`（アライアンス／リスト名 WEB_ → LP／それ以外の自社 → 白地）
- 1 件のポイント＝付与ポイント表の**合計付与P**（`pointFor`：商材名区分2・獲得方法・受注日）
- 内訳は付与ポイント表の「配信の内訳」（コラボ／AU／クレカ／NURO／でんき／その他）
- `合計件数：x.xP`、`白地：x.xP（コラボ1.2／でんき0.4）` の形。**0 の内訳は消す**（例「AU0」は出さない）。獲得方法の合計が 0 なら `アライアンス：0.0P` と括弧なし
- 付与ポイント表に無い商材があれば、最後に `⚠ポイント表に無い商材：au光プラス 1件` を出す（数え漏れを隠さない）
- キャンセルの扱い：**商材ステータスが「キャンセル」の案件は数えない**（東海林さんに確認中。変えるなら 1 か所で切り替えられるようにする）
- **クレジットカードは顧客一覧に入らない**ので、管理表と同じ **クレジットカードの 8 アプリ**（`KINTONE_KANRI_CREDIT_APPS`・`KINTONE_KANRI_CREDIT_TOKEN_<アプリ>`・`kanri-import.server.ts` の `safeFetchCredit` と `CREDIT_FIELDS`）も読む（東海林さん 2026-11-12）
  - 当日の判定は管理表と同じ日付の欄（`日付_4`、無ければ `紹介日`）。商材は `ドロップダウン_12`、無ければ `商材名区分2`
  - 獲得方法：クレカのアプリに事業名・リスト名で見分けられる欄があればそれで判定し、無ければ「白地」とする。どちらにしたかと、欄の有無を報告に書く
  - 1 アプリでも読めなかったら、本文の最後に `⚠クレカのアプリ <番号> を読めませんでした` と出し、読めた分だけで数える（配信は止めない）
  - 部品は管理表と共通にする（読み方を 2 か所に書かない）

### 事業ごと（■ヒカリのプロ など）

- **電気開始受付センターは出さない**。並びは ヒカリのプロ → 電気お申込み受付窓口 → **フレッツ**（フレッツは今の LP の事業マスタ・Kintone 251 から。今は本文に出ていなければ出す）
