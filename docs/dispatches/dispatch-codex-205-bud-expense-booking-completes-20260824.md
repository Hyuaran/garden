# Codex-205 仕分け情報を入力したら「完了」へ移す（弥生CSVは完了タブから）

- 発行日: 2026-08-24
- 対象画面: Bud 経費精算（`/bud/expenses`）の**仕訳待ちタブ**と**完了タブ**
- 作業ツリー: `C:\garden\a-bloom-008`（`main d27dc3f` 起点）

---

## 0. なぜ変えるか（★業務の訂正・2026-08-24 東海林さん）

いまの作りは「弥生CSVを書き出した瞬間に完了になる」。これが**業務と違う**。

- **仕分け情報（仕分け日・仕分け法人名・決算区分）を入れた時点が「仕訳した」＝完了**
- **弥生CSVを出すタイミングは仕訳と同時ではない**（後日まとめて出す・決算前に1年分出す等）

実際に起きたこと：仕訳待ちタブで18件に仕分け情報を入れ「保存しました」と出たのに、
行が仕訳待ちタブに残り続けた（いまの作りでは正しいが、業務としては完了に移るべき）。

FM過去分の取り込みルール「3つの入力があるもの＝完了」とも、この新しい流れは一致する。

---

## 1. 変える内容

### 1-1. 仕分け情報の保存＝完了にする
- 「仕分け情報を入力」で保存が成功したら、**その行の `status` を `journalized` に変え、
  `journalized_at`（現在時刻）と `journalized_by`（操作した人）を記録する**
- 画面上はその場で仕訳待ちタブから消え、完了タブに現れる
- 保存メッセージは `18件の仕分け情報を保存し、完了へ移しました。` のように**移ったことが分かる文言**にする
- 3つのうち一部だけしか入らないケースを作らない（いまと同じく、まとめて保存）

### 1-2. 仕訳待ちタブから弥生CSVのボタンを無くす
- 「弥生CSVを書き出す」ボタンと「CSV書き出しは法人を1つ選択すると有効になります」の案内を撤去
- 全選択チェック・台帳形式Excel・仕分け情報を入力・選択を削除は残す
- 埋め込みHTML側（モック）は触らない

### 1-3. 完了タブのボタン名を変える
- 「弥生CSVを再出力」→ **「弥生CSVを書き出す」**（初回もここから出すため）
- 動きは今のまま：仕分け法人名を1つ選ぶ／選択した行／出力履歴（日時・回数）を記録／
  **出力済みを含む選択のときだけ確認ダイアログ**（初回だけの選択なら確認なし）
- 確認ダイアログの文言は今のまま（「…出力済みです…再出力しますか？」）

### 1-4. API側
- `/api/bud/expense-booking/export` の**初回モード（journalize_pending を journalized に変える動き）は使われなくなる**。
  API からそのモードを**取り除く**こと（画面から呼ばれない機能を残すと事故のもと）
- 完了タブからの出力（reexport モード）を正とする

## 2. 既に入力済みの18件（移行措置）

仕訳待ちのまま仕分け情報が入っている行が**18件**ある（今日の操作分。
`status = journalize_pending` かつ `booking_date is not null`）。

→ **この18件を journalized へ移す migration を書くこと**：
```
status = 'journalized', journalized_at = booking_set_at
```
の形（`journalized_by` は `booking_set_by` を使う）。対象は
`status='journalize_pending' and booking_date is not null and deleted_at is null` のみ。
**SQLを置くところまで。本番適用はしない**（適用は東海林さん）。

※FM取込の仕訳待ち335件は `booking_date` が無いので対象外（正しい）。

## 4. テスト

- 仕分け情報を保存すると `journalized` になり、`journalized_at`／`journalized_by` が入ること
- 保存後、仕訳待ちタブの一覧から消えること（再読み込みで完了タブに出ること）
- 仕訳待ちタブに弥生CSVのボタン・案内文が無いこと
- 完了タブのボタンが「弥生CSVを書き出す」で、未出力だけの選択なら確認なしで出ること
- 出力済みを含む選択では確認が出ること（回帰）
- export API の初回モードが**呼べない**こと
- 台帳形式Excel・ページ送り・集計の回帰
- **文字が幅からはみ出さないこと**
