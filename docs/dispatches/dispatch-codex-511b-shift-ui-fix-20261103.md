## 直し方
### A. 1日の入力（ShiftDays・本人の画面・責任者の小窓・LIFF・スマホで共通）
```
 ┌12/1(月)────┐┌12/2(火)────┐┌12/3(水)────┐┌12/4(木)────┐
 │[14:00〜21:00 ▼]││[休み        ▼]││[15:30〜21:00 ▼]││[休み        ▼]│
 └──────────┘└──────────┘└──────────┘└──────────┘
 ┌12/6(土)────┐  ← 土日祝はうすい色の枠。定休日は灰色で「定休日」と出し、選ぶ欄なし
 │[10:00〜21:00 ▼]│
```
- 1日＝1つの小さな枠。中は日付と**選ぶ欄1つ**（「休み」「14:00〜21:00」「14:30〜21:00」…「18:00〜21:00」。土日祝は 10:00 から）。ラジオはやめる
- 並びは `grid-template-columns: repeat(auto-fill, minmax(150px, 1fr))`。PC の小窓で4列前後 → 31日がスクロールなしで収まること。スマホ 375px で2列・横スクロールなし
- 選ぶ欄の文字は 16px（iPhone で拡大されないため）
- まとめて設定：「平日 [14:00〜21:00▼] 土日祝 [10:00〜21:00▼] ［全部の日に入力する］」を1行（狭い幅では折り返す）
- 出勤日数・合計時間の行は残す
- css は form-kit（`form-kit.module.css`）の中に置く。`shift.css` のような画面ごとの css は増やさない（今の shift.css は表の部分以外は form-kit へ移す）

### B. みんなのシフトの表
```
 氏名        │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │…│31 │
             │ 月│ 火│ 水│ 木│ 金│ 土│…│ 水│   ← 日と曜日の2段・印なし（並べ替えなし）
 宮永チーム ────────────────────────────── ← 左寄せで見える（氏名の列と同じく左に固定）
 大塚 響     │14:00│ 休 │15:30│…
 合計時間    │ 42 │ 28 │ 35 │…                ← 時間は数字だけ（列幅を取らない）
```
- 日の列は 56px 前後。31日でも PC 幅（1280px）で横スクロールが少なくなるように
- 「休」はうすい文字色。出勤は時刻（14:00）
- 土日祝の列の見出しはうすい色、定休日の列は灰色で見出しに「定休」
- 氏名の列は左に固定・見出し「氏名」
- 行全体を押すと小窓（今のまま）。小窓は A の部品なのでスクロールバーなし
- 「最終更新」はその月の希望・確定の一番新しい更新日時（2026/11/16(日) 10:05:12）。まだ何もなければ UpdatedStamp を出さない
- タブの下の重複見出し「みんなのシフト」は消す。月の選ぶ欄だけ置く
- 未提出の人：「提出 3/15人」の横に「未提出 12人」を出し、名前はその下に小さめの文字で並べる（今の文の形でよいが、読みやすく）

### C. 定休日の候補
```
 定休日の候補（合計時間が少ない順）
 [12/2(火) 28時間] [12/9(火) 30時間] [12/16(火) 31時間] …  ［すべての日を表示］
```
- 押せる小さなボタンを横に並べる（折り返し）。最初は少ない順に10日だけ。［すべての日を表示］で全部
- 定休日に選んだ日は濃い色（ティール）で「定休日」と出る。もう一度押すとやめる（確認の小窓なし・押してすぐ反映、失敗したら元に戻して知らせる）
- 日付は「12/2(火)」の形。「2026-12-03」の形は出さない
