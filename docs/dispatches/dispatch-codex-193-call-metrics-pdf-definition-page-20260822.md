## 0. 状況

**「定義方法」だけ、2ページに決め打ちで分けたままの古い作りが残っている。**

`CallMetricsPdfDocument` の中で、定義方法は `<Page>` が2つに分かれている。

- 1つ目：見出し「定義方法」＋ 集計の定義／休憩時間割／コール履歴のフラグ名→ポータル表示名
- 2つ目：見出し「定義方法（続き）」＋ 結果フラグの扱い（分類ルール）

見出しの分を除くと実質**約240pt**なので、**1ページに収まる**（40ptほど余る）。

## 1. やること

**定義方法を1つの `<Page>` にまとめ、入るだけ入れて自然に次ページへ流す形にする。**

- `<Page size="A3" orientation="portrait" wrap>` を **1つ**にし、4つのブロックを順に並べる
  1. 集計の定義
  2. 休憩時間割（★の注意書きを含む）
  3. コール履歴のフラグ名 → ポータル表示名
  4. 結果フラグの扱い（分類ルール）
- 見出しは1ページ目だけ「定義方法」。
- **「定義方法（続き）」の決め打ちページは削除**し、代わりに従業員ごと・リストごとと同じ
  `ContinuationLabel`（2ページ目以降に「定義方法（続き）」が出る仕組み）を使うこと。
- 項目が増えて1ページに入らなくなったら、**自動で2ページ目に流れる**こと。
  いまのデータでは**1ページに収まる**のが正解。

### 注意
- 表の途中でページが割れても、表の見出し行は次ページで繰り返されること（いまの `fixed` の仕組みを維持）
- `SECTION_DEFINITION` のマーカーは残すこと（テストが使っている）
- ★の注意書きは休憩時間割の直下のまま
