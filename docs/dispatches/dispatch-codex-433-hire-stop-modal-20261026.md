# Codex-433：入社の登録が途中で止まったときの表示（小窓・赤字・◎✕・具体的な理由）（2026-10-26）

## 目的（東海林さん 2026-10-26）
足立さんの［入社］→［登録する］が Kintone 名簿の段階で止まったとき：
- 手順の一覧とエラーの文が**操作の列からはみ出して見切れた**。
- 「同じ方が別の社員番号で名簿に登録されています。事務で確認してください」では**何が起きたか分かりにくい**。
- 東海林さんの指示：［登録する］の後に止まったら**そのままエラーを小窓（モーダル）で出す**／一覧のエラーの文言は**赤字**／手順の印は**✓ではなく◎**、**できていない項目は全部✕**。

- 小窓は今の修正・入社の確認と同じ `<dialog>`（showModal・Esc／外で閉じる・スマホではみ出さない・明暗）。
- ［登録する］→処理中は今のまま。止まったら一覧を読み直したうえで、この小窓を自動で開く。全部できたら小窓は出さず、その人は「入社後の確認」タブへ移る（今のまま）。
- 止まっている行（status=hiring で steps にエラーがある行）は、**行を押すと修正ではなくこの小窓**が開く（修正は入社処理前の行だけ＝今のまま）。処理中（エラーなし・処理中）の行は「処理中」と出して押しても何もしない。
- 状態の短い表示：社員番号で止まった＝「番号で止まっています」／KOT＝「KOT で止まっています」／名簿＝「名簿で止まっています」／Garden 反映＝「Garden 反映で止まっています」。赤字（`--danger`）。
- 手順の印：できた＝◎（ティール）／止まった＝✕（赤）／まだ＝✕（補助色）。✓ は使わない。

## エラーの文を具体的に（`src/app/system/onboarding/_lib/hire-candidates.server.ts` の HireError）
「事務で確認してください」で終わらせず、**どこに・何が・どの番号で・何をすれば進むか**を書く。値はその場のデータから入れる。例：
- 名簿に同じ方が別の番号：「Kintone 名簿に『{氏名}』さん（生年月日 {生年月日}）が別の番号（社員番号 {値 or なし}／打刻ID {値 or なし}）で登録されています。名簿のその方の社員番号と打刻ID を {番号} に直してから［続きから］を押してください。」
- 名簿に同じ氏名・生年月日が複数：「Kintone 名簿に『{氏名}』さん（生年月日 {生年月日}）が {件数} 件あります。重複しているレコードを 1 件にしてから［続きから］を押してください。」
- 同じ社員番号が別の方：「社員番号 {番号} は KOT／Garden で別の方（{相手の氏名}）に使われています。…」
- KOT 停止中・Kintone の権限・Garden 反映失敗・アカウント準備失敗も、同じ考え方で「何が・次に何をする」を 1〜2 文で。
- 個人情報（住所・口座など）は入れない（氏名・生年月日・番号まで）。
