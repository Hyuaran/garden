## 目的（東海林さん）
「マニュアルのタブは開発ボードみたいにしたい。まだないとこはグレーアウトで」

## 今と、こうしたい
- 今：/system/manuals のタブは文字だけ「Garden とは／System／Bud」（マニュアルのあるモジュールだけ）。
- こうしたい：開発ボード（/system/dev-board）のタブと同じ形。**アイコン（24px）＋その下に小さな名前（11px）**を横に並べ、選んでいるタブはティールの太い下線とティールの文字。**全モジュールをいつも並べ**、マニュアルがまだ無いモジュールは**グレーで押せない**（開発ボードの `disabled` と同じ見た目＝薄く・白黒・押せない）。

```
System / マニュアル
マニュアル
 [本]      [□]     [木]   [葉]  [蕾]   ...  [川]                       [歯車]
Garden とは System  Soil  Root  Bud   ...  Rill
━━━━━━━──────────────────────────────────────────────
（Garden とは の本文）
```
（Garden とは・System・Bud 以外は今はグレー）

## やること
1. **共通部品にする**：開発ボードのアイコンのタブの見た目（`src/app/system/dev-board/board.module.css` の `.tabs` 系）を、`src/app/system/_components/SystemTabs/` に `variant="icons"` として移す。開発ボードもその variant を使うように直し、**開発ボードの見た目は変えない**（並び・幅・グレー・下線そのまま）。
2. **マニュアル**（`src/app/system/manuals/` の ManualsHubClient ほか）：
   - タブの並び＝「Garden とは」→ 開発ボードと同じ順のモジュール（System → `GARDEN_SHELL_MODULES` の順）。「共通」は出さない。

   - マニュアルが登録されていないモジュール（`MANUAL_MODULES` に無い）は `disabled`・マウスを乗せると「まだマニュアルがありません」。
   - マニュアルはあるが、その人が見られないモジュール：グレーにはせず**出さない**（閲覧権限の決まりのまま）。
   - URL の `?tab=` はそのまま。グレーのモジュールを `?tab=` で直接開いたら「Garden とは」を出す。
   - タブの行の右端の歯車は今のまま。
3. アイコンのタブはモジュールが多いので、狭い幅ではタブの行の中だけ横スクロール（ページははみ出さない）。
