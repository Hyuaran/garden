## 1. Bud のサイドバー（作りかけをグレー）
対象：`src/app/bud/_components/bud-garden-menu.ts`・`BudShachoShell/BudShachoShell.tsx`（＋css・テスト）。
```
 ダッシュボード          ← グレー（押せる）
 入金管理                ← グレー
 請求書管理              ← グレー
 経費精算                ← ふつう
 給与管理                ← グレー
 振込管理                ← グレー

 マスタ管理              ← グレー
```

- メニューの項目に `preview: true`（見本の画面）を持たせ、文字と線画アイコンを薄いグレー（ライト・ダークとも読めるが一段薄い色。今の補助文字の色の変数を使う）にする。**押せる・開けるのは今のまま**（見るのは止めない）。
- マウスを乗せたとき・スマホの三本線メニュー・下メニューでも同じ見た目。選ばれている（今いる）画面なら、グレーのままで選ばれている印は付ける。

## 2. 事業の収支：明細を小窓に
対象：`src/app/bud/profit/broadband/BroadbandTable.tsx`・`broadband.module.css`・テスト。小窓は共通部品 `src/app/system/_components/Modal/Modal.tsx` を使う。
- 今ページの下に出している「収支の明細」（`Details`）と「NTT原価の明細」（`reference`）を、どちらも小窓で出す。下に出す表示は無くす。
```
┌ 株式会社Crescere ・ 2026年8月 ──────────────── × ┐
│ 口座と金額が違います                          （赤の欄だけ・赤の文字）│
│   予定（税込）  246,400 円                                         │
│   口座に届いた   114,400 円（楽天銀行 2026-08-31 カ)CRESCERE）       │
│   差            132,000 円 少ない                                  │
│ ────────────────────────────────────────────    │
│ 103_クレカ ／ クレジットカード                                      │
│   予定日 2026-08-31 ・ 実績期間 2026-07 ・ 税抜 224,000 円 ・ 状態 金額が口座と違う │
│   [Kintone で開く]  [口座の明細を開く]                               │
│ （欄の中の行が複数なら、行ごとにこの段をくり返す）                    │
└──────────────────────────────── [閉じる] ┘
```
- 見出し＝取引先 ・ 月（合計の列なら「期間の合計」）。
- **赤の欄の「何がどう違うか」**：行ごとの状態で書き分ける（`statusLabels` と `recon_bank` を使う）。
  - 金額が口座と違う：予定（税込）・口座に届いた金額（銀行・日付・摘要）・差（「○円 多い／少ない」）。
  - 口座に見つからない：「予定日を過ぎても入金（支払い）が見つかりません。予定 ○円（税込）・○月○日まで探しました」。探した期限は今の照合の決まり（予定日の後の日数と翌月末の遅い方）を `reconcile.ts` から関数にして使い回す（同じ計算を二度書かない）。
  - 候補が複数：同じ金額の候補を一覧（銀行・日付・摘要）で。
  - 赤でない欄は、この段を出さない。
- **リンク**：
  - 「Kintone で開く」＝今の `kintoneLink`（別タブ）。
  - 「口座の明細を開く」＝口座の照合に使った明細がある行だけ。`recon_bank[].mf_account_id` から Garden の口座の明細の画面（`/bud/bank/accounts/<mf_account_id>?period=fy:<年度>`。年度は明細の日付の年度。今の `kanden-sync.ts` のリンクと同じ形）を別タブで開く。
  - 代理店支払いの子の行（`agent-`）は Kintone のリンクを出さない（今のまま）。
- NTT原価の小窓は、今の中身（Kintone の金額・税込・口座の参考額・差・口座の行）をそのまま小窓に。口座の行ごとに「口座の明細を開く」。
- 小窓は Esc・×・［閉じる］・外側を押すと閉じる。並べ替え中は開かない（今のまま）。375px では横いっぱい（はみ出さない・横スクロールを出さない）。

## 3. 事業の収支：事業ごとのタブ
- 上の表の 8 つのタブ。今の「ブロードバンド事業」「SES事業」の 2 つのタブを置き換える。タブは SystemTabs（`variant` は今のまま）。
- ブロードバンド事業＝今の表と同じ（全部）。ほかのタブは、表の行を事業内容（`business` の頭の番号）で絞る。**小計・総合計はそのタブの中の行だけで計算**。
- どのタブにも入っていない新しい事業内容が増えたら、ブロードバンド事業にだけ出る（ほかのタブには出さない）。
- NHK事業・SES事業＝「○○事業の収支は、現在作成中です。」（今の SES と同じ形）。
- 期間・色の凡例・並べ替え・閲覧権限の歯車は、表のあるタブで今と同じに使える（並べ替えの順番はタブ間で共通の 1 つでよい）。
- 最後に開いたタブを人ごとに覚える（`localStorage`・今の開閉の覚え方と同じ作り・読めなくても動く）。
- 閲覧権限の説明「ここに入れた人は、事業の収支（すべての事業のタブ）を見られます」はそのまま。
