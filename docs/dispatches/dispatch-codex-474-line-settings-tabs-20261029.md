- 行を押すと共通 Modal（幅 `min(640px,100vw-32px)`）：
```
ブロードバンド事業・小泉チーム のメニュー
┌─────────────────────────────┐
│  （メニューの絵 menuDefinition(group).image の jpg）  │   ← 幅いっぱい・縦横比そのまま
└─────────────────────────────┘

- ボタンの並びと「押したとき」は `menuDefinition(group, contacts, liffId)` の areas から作る（決まりを二重に書かない）。位置の名前は bounds から：4 つ＝左上・右上・左下・右下／3 つ横並び＝左・中央・右／2 つ＝左・右。ボタンの名前は絵の文字と同じ（申告フォーム・シフト・担当者・宮永さん／紐づき前＝お問い合わせ・会社のホームページ）。

- 「このメニューの人」は名前を並べる（従業員以外の方は人数だけ「紐づいていない友だち 452 人」）。

## 4. あいさつ文タブ（一覧／カードの切り替え）
- 右上の HeaderViewToggle で切り替える（あいさつ文タブのときだけ押せる・ほかのタブではグレー）。覚え方は deliveries と同じ localStorage（キー `garden.line.greeting.viewMode`）。最初は一覧。

```

- カード：今の表示のまま（［編集する］［自分に試しに送る］も今のまま）。
