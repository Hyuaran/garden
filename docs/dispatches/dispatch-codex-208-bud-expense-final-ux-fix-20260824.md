## 1. くるくるが「全画面」になっていない（★一番大事・実機で確認済みのバグ）

### 実機で何が起きたか
完了タブで「台帳形式で書き出す（Excel）」を押すと、
**画面が暗くなるだけで、くるくるも「〜しています…」の文言も見えない**ことがある。

実測値（ブラウザで計測）:
- オーバーレイは `position: fixed` なのに、実際の描画範囲は
  **x=306, y=-345, 幅623, 高さ4320**（画面は 1333×792）
- つまり画面全体ではなく**埋め込みパネルの範囲だけ**を覆っている
- くるくると文言は「高さ4320の中央」＝画面のはるか下に描画されるため、目に入らない
- ヘッダー・サイドバー・右の Activity 欄は覆われず、そのまま操作できてしまう

### 原因
`/bud/expenses` の各タブは埋め込みHTMLのポータル配下に描画されており、
祖先に `transform` 等があるため、`position: fixed` が**画面基準にならず祖先基準になる**。

### やること
`src/app/bud/expenses/_components/ExpenseProcessingOverlay.tsx` を
**`react-dom` の `createPortal` で `document.body` 直下に描画する**ように変える。

- 新しいライブラリは不要（`react-dom` は既にある）
- `open` が false のときは今までどおり `null` を返す（SSR中に `document` に触らないこと）
- 呼び出し側（承認待ち・完了待ち・仕訳待ち・完了の4タブ）は**変えない**（部品の中だけで直す）
- 直した後の合格条件（Claudeがブラウザで再実測します）:
  - オーバーレイの描画範囲がビューポート全面（ヘッダー・サイドバーも覆う）
  - くるくると文言が**スクロール位置に関係なく画面中央に見える**

### テスト
- オーバーレイが `document.body` 直下に描画されること（`parentElement` の検証）
- 表示・解除・件数・文言の既存テストが引き続き緑であること

## 2. 完了タブの回帰テストが「コメント」を見て合格している

`ExpenseDonePanel.tsx` を全面的に整形し直した（1行スタイル→複数行、557行追加）。
整形すると既存の回帰テスト（`expense-done.test.ts` ほか、ソースを文字列で照合するテスト）が
落ちるため、**旧コードの断片をコメントとして貼り付けてテストを通している**:

```
// Compact reference forms retained for source-level regression checks.
// disabled={corpId === "all" || selectedRows.length === 0
// ...
```

これではテストは今後、実コードではなくコメントを照合して合格し続ける（テストの意味がなくなる）。

### やること
- `ExpenseDonePanel.tsx` の**整形だけの変更をすべて元に戻す**（元のコンパクトな書き方に戻す）
- 今回の実変更（`expense_kind` の追加・バッジ・オーバーレイ・`setProcessing`）だけを残す
- 上記の**コメント退避ブロックを削除**する
- `expense-done.test.ts`・`expense-applicant-name.test.ts` 等の文字列照合が
  **実コードに対して**緑になることを確認する（テスト側の期待文字列は変えない）
