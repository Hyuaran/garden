| 桁や長さがそろうもの | **中央** | 日付・日時・年月、社員番号などの番号・コード |

## やること
1. `src/app/system/_components/DataTable/DataTable.tsx`：列の定義に `align?: "text" | "fixed" | "mark" | "number"`（text＝左／fixed＝中央／mark＝中央／number＝右）を足す。**指定が無いときは列の `type` から自動**（日付・日時＝fixed、金額・数値＝number、それ以外＝text）。数字の列は `font-variant-numeric: tabular-nums`。
2. 全画面の表を 4 種類にそろえる：
   - DataTable を使う画面＝各列に正しい `align` を付ける（自動で合わないものだけ）。
   - 生の `<table>` の画面（System・Root・Bud・Sprout・Rill など `grep -rl "<table" src --include=*.tsx`）＝列ごとに CSS で同じそろえ方に。共通のクラス（`globals.css` に `.garden-cell-text`／`-fixed`／`-mark`／`-number` など）を作って使う。
   - 「みんなの入社手続き」（Codex-435 で DataTable 化）は上の見本どおり。あわせて、今は細い白い枠（`styles.panel`）の中で横にはみ出しているので、ほかのタブ（入社予定者など）と同じく**枠なしで横幅いっぱい**にする（`src/app/system/onboarding/AdminOnboardingList.tsx`）。
   - 口座残高・カード利用（`src/app/bud/bank/`）も対象（未コミットの変更は無くなった）。
3. スマホ幅で表が横スクロールになる画面でも、そろえ方は同じ。
4. テスト：DataTable の自動判定（日付→中央・金額→右・文字→左・align 指定が優先）。
