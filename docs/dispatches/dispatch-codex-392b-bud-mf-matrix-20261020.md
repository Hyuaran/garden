- 口座名「みずほ銀行｜HR」の **｜の左＝銀行、右＝法人の略号**（会社名に読み替えて表示）。｜が無い・読めない略号は「その他」の行に
- 1 つの欄（法人×銀行）に口座が 2 つ以上あるときは合計して 1 つの欄に（下に小さく口座の数）
- 口座が無い欄は「—」。balance_mode=manual_check の口座は「MFで確認」（その欄・合計に入れない。合計の下に小さく「MFで確認 n 口座を除く」）
- **増減**：その口座の今の残高 −「今日の 0 時の残高」。増えた＝↑ ＋（緑）・減った＝↓ ▲（赤）・同じ＝±0（灰）。0 時の残高が無い（初日）は表示しない。合計の増減も同じ
- 未仕訳の件数は金額の下に小さく
- 並び替え（全権だけ）：**法人の並び（縦）と銀行の並び（横）を動かせる**（全員共通・つかんで動かす／スマホは上下・左右の矢印）。カード式の並び替えは消す
- スマホ：表は横にスクロール（法人の列は左に固定）。ページ全体ははみ出さない
- 見てよい人の絞り込みはそのまま（見られない口座の欄は「—」・合計にも入れない）。全権は全部
- 社長スタイル・明暗・表の見出しは中央・数字は右寄せ・金額は桁区切り
