## 2. 計算のルール（Excel の式から起こした）

担当者ごと・日ごとに 1 行（月の 1 日〜末日）。

| Excel | 中身 |
|---|---|
| D 日付／E 曜日 | 月の日 |
| F 状態 | 手入力（出勤＝●／公休／ゼロ／空） |
| G 稼働h | 手入力（既定 7） |
| H〜T 件数 | **status が「出勤」の日だけ**、その担当者・その日の関電件数報告（report_time＝最終）の値。担当者名の突き合わせは **スペースを全部取って比べる**（person.name「萩尾　拓也」↔ staff_name「萩尾拓也」）。「公休」「空」は空欄、「ゼロ」は 0。同じ日に「最終」が複数あれば最後の 1 件（レコード番号の大きい方） |
| U・V | 手入力（レンタル・販売） |
| B 実数 | H〜V の合計 |
| C 個人評価実績 | Σ（件数 × 評価係数）。公休・空の日は空欄 |
| A | C と同じ（Excel は `=C4`） |
| 35 行目 | 列ごとの合計 × 評価係数（H35＝SUM(H4:H34)×H3 …）、G35＝稼働h の合計 |
| D2（合計評価実績） | SUM(H35:V35)。**実績管理の I（fieldPoints）へ** |
| B2 実数（月合計） | 上の 35 行目の実数（Excel は B2 に月の実数） |

**実績管理への受け渡し**：訪販の人の H（稼働時間）＝この表の G35、I（合計獲得P）＝D2。personMonthly の workHours／fieldPoints は**訪販の人については使わない**（画面からも入力欄を消す）。着地予想・稼働日数は今までどおり手入力。
