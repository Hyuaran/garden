## Vercelの呼び出し見積もり

- 定期呼び出しは **0回/日**。cron、ポーリングは追加していない。
- 初回の画面表示、詳細を開く、前後移動、タブ切り替え、検索、一覧のページ送り、更新マークは各操作1回。ページ境界の前後移動は一覧と1件の詳細を同じ応答で受け取る。
- 保存は保存と一覧・詳細の再取得で通常2回。ステータスが進んでページ末尾の次案件が前のページへ移る場合は最大3回。諸元の添付は署名・確定・再表示で3回。写メの転送はStorageへ直接送る。供給地点の番号を変えた場合の重複確認は、入力が落ち着いてから1回。
- 例として4人が1日あたり各2回起動、30回詳細移動、6回タブ・一覧・検索操作、2回更新、15回保存、1回添付、3回重複確認を行う場合、通常 **304回/日**。保存がすべて3回になる仮定で上限は **364回/日**。営業フォームの送信による受注化は既存の送信処理の中で行い、Vercelの呼び出しを増やさない。
