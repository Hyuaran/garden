## 0. 方針（東海林さん 2026-09-16）

> アップロードは新しく買ったリスト、またはクリーニング（買った）したリストのみ。
> リストタブの書き出しを FileMaker インポート用の形式でも出せるようにすれば、台帳から選んだリストをいったん Excel に出してアップロードし直す必要はなくなる。

つまり動線を 2 本に分ける：

```
【買ったとき】 購入先の Excel／元 Excel → アップロードタブ（購入先・購入日を選ぶ）→ 購入履歴＋台帳へ（Codex-314／335 の作りのまま）

【架電に配るとき】 リストタブで絞る → ［FileMaker 取込用（19 列）で書き出す］
                  → リスト名（回線種別＋架電開始日）を決める → 19 列の Excel が落ちる
                  → 同時に 投入履歴 に「この番号をこのリスト名で配った」が残り、台帳のリスト名・投入日が更新される
                  → 営業はその Excel を FileMaker に取り込む
```

これで「台帳から抽出 → 026 で整形 → アップロード」の往復が無くなり、投入履歴は書き出しの瞬間に自動で付く。

## 2. 書き出しと同時に「投入」として記録する

```
［FileMaker 取込用（19 列）で書き出す］を押す →

┌ FileMaker 取込用で書き出す ─────────────────────────────────────┐
│ 該当 1,240 件（自社アポ禁 3 件は除きます）                                │
│                                                                          │
│ リスト名                                                                  │
│  回線種別  [ フレッツ ▼ ]（フレッツ／アナログ／AU／クレカ／その他＝手入力）     │
│  架電開始日 [ 2026-09-17 ]                                                 │
│  → リスト名：【光回線】フレッツ_20260917                                     │
│                                                                          │
│ (✓) この番号を「配った」として投入履歴に記録する（台帳のリスト名・投入日も更新） │
│     ※ 記録すると「過去に配った番号」として次回の絞り込み・元 Excel のチェックで除外できます │
│                                                                          │
│                                        [ やめる ]  [ 書き出す ]           │
└──────────────────────────────────────────────────────────────────┘
```

- リスト名の既定：`【光回線】{回線種別}_{架電開始日 YYYYMMDD}`。回線種別の既定は絞り込みの 元回線 が 1 つならそれ。クレカは `【クレカ】{手入力}_{日付}`。手入力で丸ごと上書きも可
- 記録のチェックは**既定 ON**。OFF なら 19 列を出すだけ（試し出し用）
- 記録の中身＝**今のアップロードと同じ**：`soil_list_upload` に 1 行（`source_kind='export'`・`file_name`＝出したファイル名・購入先／購入日は null・`upload_kind` は作らない）→ `soil_list_assignment` に 番号×リスト名（リスト投入日＝架電開始日）→ **`soil_list_apply_upload` を 1,000 件ずつ**（購入履歴の insert は `source_kind='export'` のときスキップ。関数に分岐を足す＝migration `20260917000007_soil_list_export_assignment.sql`。台帳に無い番号は書き出しでは出ないので新規 insert の分岐は通らない）
- 書き出し中は既存の全画面くるくる。結果：「書き出しました：1,240 件／投入履歴に記録：新規 1,180・更新 60（【光回線】フレッツ_20260917）」。記録は「取り込みの記録」（アップロードタブ下の一覧）にも「書き出し」として並ぶ
