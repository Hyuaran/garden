# Codex-536 顧客一覧の「実績日・実績可否」の自動ルールと、配信を実績日で数える（2026-11-20）

## 背景（営業と決めたこと）
テレマ コール集計ポータルの自動配信で、立ち上げた受注が当日に数えられていなかった（受注日しか見ていない）。営業のルールは次のとおり。

- 数える日＝**実績日**。数える条件＝**実績日がその日 かつ 実績可否が「可」**。「否」は数えない
- 初めは 実績日＝受注日（＝「当日受注」）
- 立ち上げ日を入れたら 実績日＝立ち上げ日 に書き換え、実績可否＝「可」（＝「立ち上げ案件」）
- リトライ日を入れたら 実績可否＝「否」
- 後確OK日が空で キャンセル日が入っていたら 実績可否＝「否」
- 商材詳細ステータスが「管理会社まち」になったら 実績可否＝「否」・実績日を空にする（選択肢は Claude が Kintone に足す）

例：実績日 10/31・リトライ日 11/1・立ち上げ日 11/2 → 実績日は 11/2・可

## やること
### 1. Kintone 顧客一覧（アプリ 10）用の画面のしかけ `public/kintone/garden-jisseki-rules.js`
- 既存の `public/kintone/garden-auto-assignee.js` と同じ書き方（先頭の説明コメント・即時関数・配信 URL `https://garden-os.net/kintone/garden-jisseki-rules.js`）。PC とスマホの両方のイベント（`app.record.*` と `mobile.app.record.*`）
- 項目コード：受注日・実績日・実績可否（否/可）・立ち上げ日・リトライ日・キャンセル日・後確OK日・商材詳細ステータス
- 判定は純粋な関数 `applyJissekiRules(values)` にまとめる（入力＝上の値、出力＝{実績日, 実績可否}）。順番：
  1. 実績日が空なら 受注日、実績可否が空なら「可」
  2. リトライ日があり、立ち上げ日が無い（またはリトライ日より前）→ 否
  3. 立ち上げ日があり、リトライ日が無いか立ち上げ日 ≥ リトライ日 → 実績日＝立ち上げ日・可
  4. 後確OK日が空 かつ キャンセル日あり → 否（3 より強い）
  5. 商材詳細ステータス＝「管理会社まち」→ 否・実績日を空（いちばん強い）
- 呼ぶとき：作成・編集画面の各項目の change（受注日・立ち上げ日・リトライ日・キャンセル日・後確OK日・商材詳細ステータス）、保存の直前（create.submit・edit.submit）、一覧の行内編集（index.edit.change.*・index.edit.submit）
- 値が変わったときだけ書き換える。画面に出す文言は無し（静かに直す）
- 純粋な関数は `module.exports` でもテストできる形にし、`public/kintone/garden-jisseki-rules.test.ts`（vitest）で上の例と 5 つのルール・組み合わせ（立ち上げ後のキャンセル＝否、管理会社まち＝実績日空）を確かめる

### 2. 配信を実績日で数える `src/app/system/_lib/call-report-v3.ts` と `.server.ts`
- 顧客一覧の取得：`受注日 = "<日>"` → `実績日 = "<日>" and 実績可否 in ("可")`。取得する項目に 実績日・実績可否・立ち上げ日 を足す
- `reportOrders(records, date)`（顧客一覧の分）：実績日がその日・実績可否が「可」のものだけ。今のキャンセル除外（商材ステータス＝キャンセル）は残す。**クレカ（credit=true）の分は今のまま変えない**
- `Order` に `kind: "today" | "tachiage"` を足す。立ち上げ日があって 実績日＝立ち上げ日 なら "tachiage"、それ以外は "today"
- `reportPoints`：立ち上げ案件は 白地／LP／アライアンス の行から外して、最後に 1 行「立ち上げ：x.xP（LP-NURO1.4／白地-コラボ1.1）」で出す。内訳は「獲得方法の名前-まとまりの名前 点数」を ／ でつなぐ。**合計件数には含める**。立ち上げが 0 なら行を出さない
  - 例：LP の NURO 1 件が立ち上げ → `立ち上げ：1.4P（LP-NURO1.4）`
- テスト `call-report-v3.test.ts` 等を新しい形に合わせて直し、当日受注と立ち上げ案件が混ざる例・否が数えられない例を足す
- 管理表ポータル・LP の画面など、ほかで受注日を使っている所は**今回は触らない**（報告に「受注日で数えている所の一覧」として書く）
