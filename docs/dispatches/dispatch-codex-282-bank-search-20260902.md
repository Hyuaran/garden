## 1. 打った言葉の直し方（銀行）

**上から順に試し、1件でも見つかった時点でそれを返す。**

| | 直し方 | 例 |
|---|---|---|
| 1 | 打った言葉そのまま | `みずほ` → `みずほ` |
| 2 | 言い換え表を当て、末尾の「銀行」を落とす | `大阪信用金庫` → `大阪信金` ／ `みずほ銀行` → `みずほ` |
| 3 | 2の言葉の英数字を**全角**にする | `三菱UFJ` → `三菱ＵＦＪ` |

前後の空白と全角スペースは落とす。

### 言い換え表（打った言葉 → 台帳の書き方）

### 探し方

**名前と読みの両方**を見る。大文字小文字は区別しない（いまの `ilike` のまま）。

```

```

- 並びは金融機関コードの小さい順（いまのまま）。大手が上に来る
- **候補は最大20件**（いまは10件）

## 3. コードから名前を引けるようにする（新しく足す）

名前が変わっていて見つからない金融機関があるため、**逆から引ける道**を作る。

- `金融機関コード（4桁）` を入れて欄から離れたら、台帳の名前を `銀行名` に入れる
- `支店コード（3桁）` を入れて欄から離れたら、台帳の名前を `支店名` に入れる（銀行コードが入っているときだけ）
- 見つからないときは**何もしない**（打った名前を消さない）
- すでに名前が入っていても、コードから引けたら**その名前で上書きする**（台帳の書き方に揃えるため）

`/api/system/onboarding/lookup/bank` に `code=0001`、
`/api/system/onboarding/lookup/branch` に `bankCode=0001&code=210` を足す形でよい。
`name` と `code` の両方が来たら `code` を優先する。
