## 0. 何をするか

画面に出ている呼び方を、業務の言い方にそろえる。**裏の値（`status`）は変えない。**

| いまの画面の言葉 | これから |
|---|---|
| タブ名「仕訳化 / Booking」 | **「仕訳待ち / Booking」** |
| タブの中の「仕訳化」という表記すべて | **「仕訳待ち」** |
| 一覧の状態「仕訳化待ち」 | **「仕訳待ち」** |
| 一覧の状態「仕訳済み」 | **「完了」** |

---

## 1. ★一番大事な前提

**`status` の値そのものは変えない。**`journalize_pending` / `journalized` はそのまま。
**画面に出す名前だけ**を変える。

理由：値を変えると既存の全レコードを書き換えることになり、仕訳帳・損益・監査ログなど
他の機能にも波及する。画面の名前だけなら安全で、後から呼び方を変えたくなっても軽く直せる。

- DBへの migration は**作らない**
- APIの入出力に使っている文字列も変えない
- テストで `status` の値を確かめている箇所は**そのまま**（名前の表示を確かめる箇所だけ直す）

---

## 2. タブ名と、タブの中の表記

### 2-1. タブ名
`src/app/bud/expenses/page.tsx` のタブ「仕訳化 / Booking」を **「仕訳待ち / Booking」** に。

### 2-2. タブの中に残る「仕訳化」を全部「仕訳待ち」に
仕訳化タブ（`ExpenseBookingPanel.tsx` など）の中で、画面に出ている「仕訳化」という言葉を
**すべて「仕訳待ち」に統一**する。見落としが出やすいので、**画面に出る文字列を全部拾ってから直すこと。**

いま見えているもの（これで全部とは限らない。自分で洗い出すこと）：
- 上部カードのラベル「仕訳化待ち」→ **「仕訳待ち」**
- ボタン「選択を一括仕訳化」など、「仕訳化」を含むボタン名
- 見出し・説明文・空のときの案内文

**残ってよいのは、画面に出ない部分だけ**（変数名・`status` の値・コード内のコメント）。

### 2-3. 「今月仕訳済」のカード
**「今月完了」** にする（§0 の言い換えに合わせる）。

## 3. 一覧タブの状態表示

一覧（`一覧 / List`）で状態を出しているところを直す。

- `journalize_pending` の表示 → **「仕訳待ち」**
- `journalized` の表示 → **「完了」**
- 他の状態（承認待ち・完了待ち・差戻し等）の表示は**変えない**

**画面のどこに状態名を出しているかを洗い出してから直すこと。**
一覧だけでなく、他のタブや詳細の表示にも同じ名前が出ている可能性がある。
**出ている場所はすべて同じ名前にそろえる**（同じ状態が場所によって違う名前で出ない）。

## 4. 「完了」タブを新しく作る（★東海林さん指定・2026-08-24 確定）

**仕訳が済んだもの（`status = journalized`）だけを表示するタブ**を新設する。

### 4-1. 置き場所と名前
- タブ名は **「完了 / Done」**
- 並びは **「仕訳待ち」のすぐ右**
  → `承認待ち / 完了待ち / 仕訳待ち / 完了 / 一覧 / 削除済み / 区分マスタ`
- ★**「完了待ち / Final」と隣り合う**ので、見間違えないようにすること。
  日本語が似ているぶん、英字（Final と Done）が読める大きさで出ていること

### 4-2. 何を出すか
- `status = journalized` のものだけ（削除済みは出さない）
- 出す項目：**申請者／レシート日付／区分／店名／金額／仕分け日／仕分け法人名／決算区分**
- **仕分け法人名で絞れる**こと（仕訳待ちタブと同じ絞り込みの作法に合わせる）
- **期間で絞れる**こと。**既定は今月**
  （全期間を既定にすると、年を追うごとに重くなるため）
- 並びは **仕分け日の新しい順**
- 上に **件数と合計金額（税込・税抜）** を出す。書き方は仕訳待ちタブに合わせる

### 4-3. できること
- **台帳形式で書き出す（Excel）** を置くこと
  - 理由：いまこのボタンは仕訳待ちタブにしかなく、弥生CSVを出した時点で対象から消える。
    **完了したものを後から台帳形式で出せる場所が無くなってしまう**ため、ここに置く
  - **状態を変えない読み取り専用のまま**（仕訳待ちタブと同じ実装を使い回す）
- **弥生CSVの再出力はしない**（二重計上を防ぐため）
- **この画面から状態を戻したり、値を書き換えたりしない**（見るだけ＋台帳書き出しのみ）
