# Codex-449b：最低賃金マスタ（大阪）と雇用契約書・入社手続きへの反映（2026-10-27）

## 目的（東海林さんの決定）
雇用契約書に最低賃金を書く欄がある。大阪の最低賃金を Garden に持たせ、契約書と入社手続きで自動で使う。

## 先に読む
- 雇用契約書：`src/app/root/contracts/_lib/employment-contract.ts`（hourlyWage）・`employment-contract-pdf.server.tsx`（「1. 基本賃金　時給 ［ … ］ 円（大阪府最低賃金額に準ずる）」）・`src/app/root/contracts/page.tsx`
- 入社手続きの事務の欄（月給・基本給・週の所定時間）：`src/app/system/onboarding/` の admin まわり・Codex-449 で足した［書類の PDF を作る］
- Root の画面の型：銀行口座マスタ `/root/bank-accounts`（commit 21c386fb）と同じ社長スタイル（正本 §2.5・DataTable・表の中身のそろえ方）・閲覧権限の歯車（`src/lib/auth/root-view-scopes.ts` に 1 画面足す）

## やること
### A. DB（migration を作るだけ・本番に当てない）
- 表 `root_minimum_wages`：id・prefecture（'大阪府' など）・hourly_amount（int・円）・effective_from（date）・source_url（text・任意）・created_by・created_at・updated_at。(prefecture, effective_from) で一意。
- RLS：読む＝ログイン中の在籍者、書く＝super_admin だけ（API も同じ判定）。
- 初期データ：大阪府 1,177 円（2025-10-16 から）／大阪府 1,231 円（2026-10-01 から・source_url＝https://www.rengo-osaka.gr.jp/info/saitei_chingin.html）。
- 関数（SQL か TS どちらでも）：`minimumWageAt(prefecture, date)`＝その日に効いている額（effective_from <= date の最新）。

### B. 画面「最低賃金マスタ」（/root/minimum-wages）
- Root のサイドバーで銀行口座マスタの近くに。表＝都道府県・時給（右寄せ・円）・いつから（中央）・出典・最終更新（秒まで）。
- ［追加］［修正］は全権管理者だけ（小窓は共通 Modal・保存前に ChangeConfirm）。削除は無し（間違いは修正）。
- 今日の日付が 10 月 1 日を過ぎていて、今年の effective_from の行が無ければ、上に「今年の最低賃金が未登録です。大阪労働局の発表を見て追加してください」と黄色で出す。
- 閲覧権限の歯車（page_key `root-minimum-wages`・既定は Root の他のマスタと同じ）。

### C. 雇用契約書
- 契約書の入力で、入社日（契約開始日）の時点の大阪の最低賃金を引き、**時給の初期値**にする。
- 時給が最低賃金を下回るときは保存できない（「大阪府の最低賃金（2026-10-01 から 1,231 円）を下回っています」）。API 側でも同じ判定。
- PDF の「（大阪府最低賃金額に準ずる）」の行はそのまま、時給に入った額を出す（下回る額では PDF を作らない）。
- 該当日の最低賃金が登録されていないときは、作らずに「最低賃金マスタに登録がありません」。

### C2. 雇用契約書を月給にも対応（東海林さんの会社の実物＝リンクサポートの「労働条件通知書兼雇用契約書」は「１．基本賃金　イ 月給（　）円／ロ 時給（　）円」の両方の行がある）
- 契約書の入力に「給与区分（時給／月給）」を足す（入社手続きから作るときは事務の欄の給与区分を使う）。
- PDF の賃金の 1 行目：時給＝今の「1. 基本賃金　時給 ［ N ］ 円（大阪府最低賃金額に準ずる）」、月給＝「1. 基本賃金　月給 ［ N ］ 円」。ほかの行・ページ数・レイアウトは変えない（1 行の差し替えだけ）。
- 月給の最低賃金の判定は D と同じ式（週の所定時間が無ければ作らずに「週の所定時間を入れてください」）。
- Codex-449 で入れた「給与区分が月給の書類には対応していません」の止めは外し、月給でも 3 点の PDF が作れるようにする。

### D. 入社手続き（月給の人の点検）
- 事務の欄で月給（基本給）と週の所定時間が入っているとき、1 時間あたり＝基本給 ÷（週の所定時間 × 52 ÷ 12）を計算し、入社日の最低賃金を下回ったら欄の下に赤字で「1 時間あたり約 N 円＝最低賃金（M 円）を下回っています」。保存は止めない（知らせだけ）。
- ［書類の PDF を作る］（Codex-449）で雇用契約書を作るときも C と同じ判定。

### E. 自動登録（手動登録と両方できるように）
- 元データ＝厚生労働省「地域別最低賃金の全国一覧」 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/ に付いている Excel「平成14年度から令和N年度までの地域別最低賃金改定状況」（手元の写し＝docs/dispatches/mhlw-minimum-wage-history-20261027.xlsx・2026-10 時点の URL＝ https://www.mhlw.go.jp/content/11200000/001756130.xlsx ・**毎年 URL が変わる**のでページの中のリンク文字「改定状況」から探す）。
- Excel の形：1 シート・1 行目＝年度（平成14年度…令和8年度）、2 行目＝「時間額(円)」「発効年月日」の組の繰り返し、3 行目以降＝都道府県（「大　阪」のように間に全角空白が入ることがある）。発効年月日は Excel の日付の数（シリアル値）。**大阪の行の一番右の組**が最新。読むのは exceljs（入っている）。
- 処理 `syncMinimumWagesFromMhlw()`：ページ → Excel → 大阪の最新の (時給, 発効日) → 表に同じ (prefecture, effective_from) が無ければ追加（source_url＝Excel の URL・created_by＝「自動（厚生労働省）」と分かる値）。あれば何もしない。読めない・形が違うときは何も書かずに失敗として返す。
- 呼び方 2 つ：
  1. マスタの画面に［厚生労働省から取り込む］（全権管理者だけ）→ 結果を小窓で「追加しました：1,231 円（2026-10-01 から）」／「新しい改定はありません」／失敗の理由。
  2. 定期実行の口 `/api/root/minimum-wages/sync`（GET・Bearer CRON_SECRET・Vercel cron 用）。**8〜10 月だけ処理し、それ以外の月は何もしないで ok を返す**。追加したら Garden通知（Chatwork 450125458・今の通知の部品を使う）に「大阪の最低賃金を自動で登録しました：N 円（YYYY-MM-DD から）。最低賃金マスタで確かめてください」。失敗は**障害ごとに 1 回＋回復時 1 回**だけ知らせる（記録の表に _health 行を持つ今のやり方に合わせる）。
- **vercel.json の crons には足さない**（初回は止めて配備＝Claude が本番で確かめてから足す）。
- テスト用に、今回の Excel を小さく切った見本（大阪＋2 府県・最後の 2 年度）を fixtures に置き、それで読み取りを試す（本物の通信はしない）。
