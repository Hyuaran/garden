# Codex-449c：雇用契約書を 3 種類（アルバイト・正社員・NHK 正社員〈派遣〉）に・見た目はアルバイトに合わせる・法人の角印を押す（2026-10-27）

## 目的（東海林さんの決定）
- 雇用契約書は雇用区分で中身が違う：**アルバイト／正社員／NHK 正社員（派遣）**の 3 種類。
- **見た目は今のアルバイト（クルー用）の PDF に合わせる**（`src/app/root/contracts/_lib/employment-contract-pdf.server.tsx` の作り・フォント・余白・表の線をそのまま使い、中身の文だけ種類ごとに）。
- 作る PDF には**法人の角印を押す**（甲＝会社の記名の横）。秘密保持誓約書・緊急連絡先届にも同じく押す（書式は雇用区分に関係なく同じ・法人名だけ違う＝今のまま）。

## やること
### A. 種類の決め方
- 雇用契約書の入力（Root の契約書画面・入社手続きの［書類の PDF を作る］）に「契約書の種類」（アルバイト／正社員／NHK 正社員〈派遣〉）を足す。既定＝雇用形態から（アルバイト→アルバイト、正社員→正社員、派遣→NHK 正社員〈派遣〉）。変えられる。
- 種類ごとの入力項目（例）：
  - 共通：法人・氏名・住所・契約日・雇用期間（定めなし／あり＋開始・終了）・契約更新・通勤手当の上限
  - アルバイト：時給（449b の最低賃金の判定）＝今のまま
  - 正社員・NHK：月給（449b の 1 時間あたりの最低賃金の判定）・就業時間（NHK は始業・終業・休憩）・業務内容と就業場所（既定文あり・直せる）・固定残業の有無
- 449b で入れた「月給の行を 1 行差し替える」作りは、この 3 種類の作りに置き換える。

### B. PDF
- 種類ごとに文面を持ち（`employment-contract-templates.ts` のような 1 か所）、今の PDF の部品（Row・W・Section・jaWrap・ページ割り）で組む。**アルバイトの PDF は 1 文字も変えない**（今のスナップショットのテストが通ること）。
- 1 ページに収まらないときは今のアルバイトと同じページ送りの決まりで。

### C. 角印
- 画像の元：`G:\マイドライブ\01_経理部\90_各社角印画像データ\PNG実寸\<法人>角印_実寸400dpi透過.png`（7 社：ヒュアラン・センターライズ・リンクサポート・ARATA・たいよう・壱・ストーンベース）。
- **公開フォルダ（public）に置かない**（誰でも取れてしまうため）。Supabase Storage の非公開の置き場 `company-seals`（`<company_id>.png`）から、PDF を作るサーバーの処理だけが読む。置き場を作る migration と、法人 ↔ ファイルの対応（root_companies の company_id ごと）を用意し、**画像の上げ込みは Claude が行う**（スクリプト `scripts/upload-company-seals.ts` を用意：G: の 7 枚を company_id 名で上げる・名前の対応表つき）。
- 押す位置：会社の記名（会社名・代表者）の右、実寸（約 21mm 角の表示）・少し文字に重ねる。角印が無い法人は押さずに作り、画面に「この法人の角印が登録されていません」。
- 秘密保持誓約書・緊急連絡先届（`src/app/system/mypage/_lib/todoke-pdf.server.tsx`）にも、会社名の横に同じく押す（届出画面から作る PDF も同じ部品を使う）。
