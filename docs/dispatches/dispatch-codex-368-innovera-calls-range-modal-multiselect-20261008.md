## 1. 期間で絞る（開始日時〜終了日時）

### API（`GET /api/system/innovera-calls`）
- `date=YYYY-MM-DD` の代わりに `from=YYYY-MM-DDTHH:MM`・`to=YYYY-MM-DDTHH:MM`（日本時間）。`from` だけなら `to`＝同じ日の 23:59。どちらも無ければ今日 00:00〜23:59。**互換のため `date=` が来たら その日 00:00〜23:59 と読む**
- 検証：形が違えば 400「日時の形式が正しくありません」。`from > to` は 400「開始は終了より前にしてください」。`from` が 1 年より前は 400「1 年より前の履歴は表示できません」。期間は **最長 31 日**（超えたら 400「期間は 31 日以内にしてください」）
- INNOVERA へは `start_time_start`＝`from` の `YYYY-MM-DD HH:MM:00`・`start_time_end`＝`to` の `YYYY-MM-DD HH:MM:59`。`limit=50000`・`page=1` から始め、返りが 50,000 件ちょうどなら次の page を続けて読む（上限 5 ページ）。`client.ts` の `searchInnoveraCalls` に `page` 対応を足す（短い記憶のキーは from/to/uniqid/page）
- 返りに `range: { from, to }` を入れる。`counts` はそのまま
- 録音 API（`recording/[cdrId]`）は `date=` のまま（その通話の開始日。画面が `startTime` の先頭 10 桁を渡す）。`date` の代わりに `from`/`to` は受けない

- 日付は `<input type="date">`、時刻は `<input type="time">`（分まで）。既定＝今日 00:00〜23:59

- 開始が終了より後、31 日超、1 年より前のときは「表示」を押す前に赤い文言で止める（API の文言と同じ）

## 2. 録音をモーダルで再生

```
┌──────────────────────────────────────────────┐
│ 録音の再生                                   [×] │
│ 2026-10-08 13:54  発信  【ヒカリのプロ｜LP】0120-425-838     │
│ 相手 090-4097-8843  担当 石原 孝志朗  通話時間 1:19           │
│ ┌──────────────────────────────────────┐ │
│ │ ▶  0:05 / 1:18  ━━━━━━━━━━━━━━━━━━━━━━  🔊 │ │
│ └──────────────────────────────────────┘ │
│ ダウンロードや削除はできません。聞いた記録は残ります。       │
└──────────────────────────────────────────────┘
```
- 「再生」を押すと画面中央にモーダル（背景は半透明の濃紺・`role="dialog"`・`aria-modal`）。中に通話の情報と `<audio controls autoPlay controlsList="nodownload">`。×・背景クリック・Esc で閉じる。**閉じたら音声を止める**
- 一度に開くモーダルは 1 つ。別の行の「再生」を押したら前のを閉じて開き直す
- 再生に失敗（403／409／5xx）したらモーダルの中に日本語の理由（「通話中は再生できません」「この録音は聞けません」「INNOVERA に接続できませんでした」）
- 既存の「行の下に `<audio>` を出す」作りは消す
- モーダルの見た目＝`innovera-calls.module.css` に `.modalBackdrop`・`.modal`・`.modalHead`・`.modalBody` を足す（角丸 8px・カード色・影。ダークでも読める）。スマホ幅では左右 16px の余白で全幅

## 3. 担当＝複数選択・既定は自分・「自分だけ」のチェックは廃止

- 「自分だけ」のチェックボックスは**消す**。API の `mine` は使わない（残しても害は無いが画面からは送らない）
- 担当の選択＝ボタンを押すと開く小さな一覧（チェックボックス付き）。候補＝その期間の通話に出てくる担当を**人単位**（従業員名。名前が引けない内線は内線番号のまま）。各候補の値＝その人の内線（カンマ区切り）
  - 一覧の上に「全員を選ぶ」「自分だけにする」「選択を外す」の 3 つ
  - **既定＝自分**（`ownExtensions` に当たる候補を選んだ状態。自分の内線が無い人（内線未登録の管理者など）は既定「全員」）
  - 何も選んでいない＝全員
  - ボタンの表示：「担当：自分（東海林 美琴）」「担当：3 人」「担当：全員」
  - 候補は「表示」のたびに期間の通話から作り直すが、**選んでいた人は候補に残っていれば選んだまま**にする
- API へは選んだ人の内線を `extension=` で複数渡す（既存の複数対応をそのまま使う）
- 権限が `own` の人は担当の欄そのものを出さない（従来どおり自分の行だけ）
- 一覧は `role="listbox"`／`aria-multiselectable`、Esc と外側クリックで閉じる。`datalist` は使わない
