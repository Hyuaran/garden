# Codex-498 重複する表の絞り込みの整理（2026-10-30）

## 実装

- 公式 LINE「人とタグ」の上部6箱を削除。雇用形態・事業・在籍・役割・チーム・自由タグは既存の列の見出しから選ぶ。
- 複数の自由タグを持つ人もタグ単位で選べるよう、共通 DataTable の `filterValue` は文字列の配列にも対応。同じ列の選択は OR、列同士は AND。タグなしは「—」で選べる。既存の文字列を返す列の動作は維持。
- 一斉送信の宛先指定は残し、その状態を `recipientTags` に改名して一覧の絞り込みから切り離した。送信確認・送信のタグ指定にも同じ状態を使用。
- Sprout の「状況」と「期間」を削除。「状況」は未設定も見出しから選べる。「期間」はデータ取得条件ではなく読み込み済み応募日の月による絞り込みだったため、「応募日」の見出しで月を複数選ぶ形へ移動。`defaultFilters` で初期表示の今月を維持し、見出しの「解除」で全期間を表示できる。
- 不要になった Sprout の状態・選択肢・上部の絞り込み処理・BoxSelect import を削除。名前・電話の検索行は引き続き使用。
- 削除した箱の状態を保持する URL 引数はなかった。LINE の `tab`、Sprout の `tab`、共通検索の `q` は従来どおり。無関係な古い引数があっても読み込まないため壊れない。
- cron・定期取得・取得タイミングの追加なし。追加の定期取得回数は **0回／日**。
