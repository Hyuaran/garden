# Codex-434：入社の登録が完了したら「完了」の小窓を数秒／入社後の確認で公式 LINE を「登録しない」にできる（2026-10-26）

## 目的（東海林さん 2026-10-26）
1. ［入社］→［登録する］（または［続きから］）で最後まで終わったとき、**「完了です」の小窓を数秒出してほしい**（今は何も出ずに行が消えるだけ）。
2. 入社後の確認の「公式 LINE」が未登録のままだと完了にならない。**ガラケーなどで登録できない人もいるので「登録しない」を選べるようにしたい**。

## 画面の絵
```
① 完了したとき（画面の真ん中・約 3 秒で自動で閉じる・［閉じる］でもすぐ閉じる）
┌ 入社の登録が完了しました ─────────────┐
│ ◎ 足立 真美さん（社員番号 1572）           │
│ ◎ 社員番号を決める  ◎ KOT に登録            │
│ ◎ Kintone 名簿に登録  ◎ Garden に反映       │
│ 次は「入社後の確認」タブで、契約書・LINE などを確認してください。 │
│                                   ［閉じる］│
└──────────────────────┘
  閉じたら一覧は今のまま（その人は「入社後の確認」タブへ移っている）

② 入社後の確認タブ：公式 LINE の列
│ 公式 LINE │
│ 登録済み            │ ← line_user_id があるとき（今のまま・自動）
│ 未登録 ［登録しない］│ ← 押すと確認「ガラケーなどで登録できないため、公式 LINE を登録しない扱いにします」→［登録しない］／［やめる］
│ 登録しない ［戻す］  │ ← 登録しない扱い。補助色の文字。［戻す］で未登録に戻せる
```
- 「登録しない」も**完了の条件を満たす**扱い（入社手続き提出・LINE〈登録済み or 登録しない〉・契約書類・FileMaker がそろえば完了）。
- 誰がいつ「登録しない」にしたかを残す（今の checklist と同じく `system_hire_candidates.checklist` に `line_skipped: {checked_at, checked_by}`）。サーバー側の checklist のキーの許可リストに `line_skipped` を足す。
- あとで本人が LINE 登録したら（line_user_id が入ったら）、表示は「登録済み」を優先。
- ① の小窓は既存の小窓と同じ `<dialog>`（showModal・Esc／外で閉じる・明暗・スマホではみ出さない）。自動で閉じるまでの時間は 3 秒。画面の読み上げ向けに `role="status"` 相当の通知も。途中で止まったときは今の「止まりました」の小窓（Codex-433）のまま。
