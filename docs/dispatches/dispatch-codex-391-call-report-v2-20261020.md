## 決まった数え方（Claude と東海林さんで確定）
### テレマ（FileMaker のコール履歴）
- 総コール・有効率：今のまま
- 平均コール数/人＝総コール ÷ 従業員数（今の「平均コール数」）
- **平均コール数/ｈ＝総コール ÷ 全員の稼働時間の合計（時間）**（例：10 人が 1 時間ずつなら 10 時間で割る）。稼働時間は今の従業員ごとの稼働時間（④§稼働時間）の合計
- **受注数＝今日「獲得」になった営業 ID（external_sales_id）の数**（同じ営業 ID は 1 件。営業 ID が空の獲得は 1 件ずつ数える）
- **前確OK／前確NG＝今日行われた前確（結果フラグ 前確OK／前確NG）の営業 ID の数**（前日以前の受注も含む・同じ営業 ID は 1 件。同じ営業 ID に今日 OK と NG の両方がある場合は**最後の結果**で 1 件）
- **前確待ち＝今日の受注（営業 ID）のうち、配信の時点までに前確OK／前確NG が一度も付いていない数**
- 受注率＝受注数 ÷ 有効コール／前確OK率＝前確OK ÷（前確OK＋前確NG）。分母 0 は「-」
- ※ かっこの 3 つの合計は受注数と一致しない（前確に前日以前の受注が入るため）＝東海林さん了承
### WEB（■事業ごと）
- 発着信・初回応答率：今のまま
- 対象外率：**削除**
- **対応顧客数＝その日の INNOVERA の LP 回線の発着信の相手の電話番号を、重ならないように数えた数**（単位「人」）
- **有効顧客数＝対応顧客数 − 対象外**。対象外＝その電話番号に一致する LP 顧客アプリの記録の対応状況が「対象外（現アナ等）」「対象外（契約不可）」「対象外（連絡つかず）」のもの（電話番号の突き合わせは今の lp-funnel と同じやり方）
- 受注数：今のまま（顧客一覧・リスト名 WEB_事業名・受注日がその日）
- **受注の内訳＝LP 顧客アプリの対応状況**：前確待ち＝「前確待ち」／前確NG＝「前確NG」／前確OK＝「申込み」。数える範囲は今の前確待ちと同じ（その日に登録された記録・重複を除く）
- 受注率＝受注数 ÷ 有効顧客数／前確OK率＝前確OK ÷（前確OK＋前確NG）。分母 0 は「-」
- 「⚠Kintone記録なし」「⚠事業に結びつかない受注」の行は今のまま
