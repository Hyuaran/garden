## 1. 見せ方をひとつにまとめる

いま `OnboardingReview` には **メールアドレス専用の `emailSlot`** がある。
世帯主で3つ目を足すと同じ作りが増えるので、**差し込み口をひとつにまとめる**。

- `emailSlot?: ReactNode` を **`slots?: Partial<Record<TextField, ReactNode>>`** に変える
- 表示のとき、その項目に差し込みがあればそれを出す（いまの `key === "email" && emailSlot` と同じ考え方）
- 呼び出し側は `slots={{ email: ..., householder_name: ..., householder_relation: ... }}` にする
- **本人の画面（提出後の確認）は差し込みなし**。いまのまま読むだけ

## 2. 事務の画面

「本人が入れた内容」の中の**世帯主の氏名**と**世帯主との続柄**を、
メールアドレスと同じように直せるようにする。

```
　┌ 本人が入れた内容 ─────────────────────────────┐
　│  …                                                  │
　│  メールアドレス   hy.09054677653@docomo.ne.jp [修正]   │
　│                  事務が入れられます                    │
　│                                                      │
　│  世帯主の氏名     未入力                    [ 修正 ]    │
　│                  事務が入れられます                    │
　│                                                      │
　│  世帯主との続柄   未入力                    [ 修正 ]    │
　│                  事務が入れられます                    │
　│  …                                                  │
　└──────────────────────────────────────┘

　【修正】を押したとき

　　世帯主の氏名     [ 吉田　陽菜          ] [保存] [やめる]
　　世帯主との続柄   [ 本人 ▼ ]              [保存] [やめる]
```

- **氏名は文字を打つ欄**、**続柄は選ぶ欄**
- 続柄の選択肢は本人の画面と同じ（`HOUSEHOLDER_RELATION_OPTIONS`）
- 【保存】を押したときだけ送る。【やめる】で元に戻す
- 保存中はボタンと欄を触れなくする
- 保存できたら「保存しました。」、できなければ理由を出す
  （メールアドレスの `emailNotice` / `emailError` と同じ形）
- **氏名と続柄はそれぞれ別に保存できる**（片方だけ直せる）
- 空にして保存できる（未入力に戻せる）

### 本人の画面の「本人」の自動入力は変えない

本人の入力画面で続柄に「本人」を選ぶと氏名が自動で入る仕組み（Codex-279）は**そのまま**。
**事務の画面には自動入力を付けない**（事務が意図せず名前を書き換えるのを防ぐため）。

## 3. 保存の道すじ

メールアドレスの `saveAdminOnboardingEmail` と**同じ作り**で足す。

- API の `action` に **`householder`** を足す
  （いまの `["renrakuhyo", "fuyou", "myNumber", "email", ...]` の並びに加える）
- 受け取るのは `householderName` と `householderRelation` の**どちらか一方または両方**
- 送られてきた項目だけを更新する（送られていない項目は触らない）
- 保存できたら、いまのメールアドレスと同じく画面を作り直す（`revalidatePath` 2本）
- 権限の見方は既存のものをそのまま使う（事務・管理者だけ）

### 決まりごと

- 氏名は前後の空白を落とす。2000文字まで（他の文字の欄と同じ）
- 続柄は `HOUSEHOLDER_RELATION_OPTIONS` にある言葉か空だけを受け付ける。
  ほかの言葉が来たら `保存できませんでした。` の扱いにする
