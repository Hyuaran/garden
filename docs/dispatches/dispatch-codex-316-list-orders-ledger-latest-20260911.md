## 3. 初めての番号は購入履歴 → 台帳（アップロードの順序を変える）

```
▼ アップロード（今の枠の上に 1 行足す）
┌──────────────────────────────────────────────┐
│ 購入先 [ データ総研           ▼ ]（必須）         │
│         ※ 初めての電話番号は、この購入先で購入履歴に入ります │
│ ┌ ここにファイルをドラッグ … ┐                      │
└──────────────────────────────────────────────┘
結果：電話番号台帳：更新 n 件・新規追加 m 件／購入履歴：新規 m 件 …
```
- **購入先**の選択欄を足す（必須）。選択肢＝購入履歴の 購入先_NEW に入っている値（件数の多い順）＋「その他（手入力）」。選ばないとアップロードできない
- `soil_list_upload` に `購入先 text`・`購入日 date`（＝アップロードした日・日本時間）を足して記録する
- `soil_list_apply_upload` の新規の番号（台帳に無い番号）の扱いを変える：
  1. **先に購入履歴へ 1 行入れる**（電話番号・購入先＝その取り込みの購入先・購入先_NEW＝同じ値・購入日＝その取り込みの購入日）。同じ 電話番号×購入先×購入日 の行が既にあれば入れない
  2. **そのあと台帳に新規追加**（今の新規追加と同じ中身＋ 最新購入先・最新購入日・購入履歴あり＝true）
- **台帳に既にある番号には購入履歴を足さない**（東海林さんの決定は「初めて購入した番号」について。再投入は購入ではない）。既存の番号は今までどおりリスト名・投入日の更新と空欄埋めだけ
- 返り値に `purchase_inserted integer` を足し、画面の結果に「購入履歴：新規 m 件」を出す。記録（取り込みの記録）にも購入先を出す
