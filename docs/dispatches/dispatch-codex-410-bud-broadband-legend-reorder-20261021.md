## ③並び順を手で動かす
- タブの行の右端の ⇅ を押すと「**並び替えモード**」（口座残高・カード利用の並び替えと同じ考え方：`src/app/bud/bank/BankAccounts.tsx` の reordering を見本に）
  - 表の各行（事業内容の小計の行・取引先の行）の左端に**つかむ印（三本線の線画）**が出る。つかんで上下にドラッグすると動かせる
  - **事業内容の行**を動かすと、その事業の取引先ごと動く。**取引先の行**は同じ事業内容の中だけで動かせる
  - マウスはドラッグ、スマホ・タブレットは**長押し（約 0.4 秒）してから**動かす（pointer イベントで両方。ネイティブの draggable だけにしない）。動かしている行は少し浮いた見た目、入る場所に線
  - キーボードでも動かせる：印にフォーカスして ↑↓（a11y）
- 並び替えモードの上に小さな操作の行：「入金 → 支払いの順に戻す」「金額の大きい順にする」「取引先名の順にする」（＝今の 3 つは**並びの初期化のボタン**として残す。押すとその順に並べ直し、そこから手で動かせる）と［終える］
- 並びは**人ごとに覚える**：localStorage `bud-broadband-order:{userId}` に `{ businesses: string[], partners: Record<business, string[]> }`。読み書きは try/catch。覚えていない事業・取引先（新しく増えたもの）は、その事業の中の末尾に「入金→支払い」の決まりで足す。もう無いものは無視
- 今の BoxSelect の「並び順」の箱（スクショの丸の一覧）はやめる
- 並び替えモード中は欄を押しても明細を開かない。合計・総合計の行は動かせない（常に一番下）
