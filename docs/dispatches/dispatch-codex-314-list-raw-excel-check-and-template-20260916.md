## 2. 元 Excel のチェック（POST `/api/soil/list/uploads/raw/preview`・manager 以上）

入力：ファイル（複数可・xlsx／xls／csv・合計 20MB・50,000 行）＋ 購入先（既存の STEP1 と同じ選び方）。**ファイル名からリスト名を作る**ので複数ファイルをまとめて上げられる。

### 2-1 種類の判定
- 見出しに「携帯番号」と「申込者名_姓」があれば **クレカ（19 列）**、それ以外で光回線の 8 見出しがそろっていれば **光回線**。どちらでもなければ「見出しが違います」で止め、足りない見出し・余分な見出しを表示（テンプレートへの導線）
- 見出しの前後の空白・全角空白は無視。列の順番が違っても見出し名で読む（026 より少し緩い。理由：営業が並べ替えても止まらないように）

### 2-2 リスト名（026 と同じ・**日付は元データのまま**）
- 光回線：ファイル名から「回線種別＋日付」。`【光回線】F×西転用J20260725.xlsx` → `【光回線】フレッツ_20260725`。種別の対応は convert.py の `KIND_MAP`（F／Ｆ→フレッツ、アナログ→アナログ）。日付が読めない・種別が読めないファイルは要確認「リスト名を作れませんでした（ファイル名：…）」にして、画面で手入力できる欄を出す
- クレカ：リスト名列の値をそのまま。**「_2」「②」などの末尾は落とさない**（026 の落とし穴を直す）
- リスト名の日付＝架電開始日（④ §8-6）。未来日でも止めない

### 2-3 整形（convert.py の関数と同じ結果）
- 氏名：姓・名が分かれていればそのまま。片方が空で空白（半角・全角）を含めば空白で分ける。**空白が無く分けられないときは全部を姓に入れて要確認「氏名の区切りなし」**（026 は namedivider で分けていた。Garden では辞書を持たず要確認に回す。営業が画面で直せる）
- 住所：空白削除・数字とハイフンは半角・カタカナは全角（NFKC を土台に、026 の `normalize_address` 相当）。都道府県が空で市町村に県名が入っているときは分ける
- 郵便番号：数字だけにして 7 桁なら `123-4567`。6 桁なら先頭 0 を補って 7 桁にし、**`system_postal_addresses` で都道府県と照合**。合えば採用、合わなければ値は書き換えず要確認「郵便番号と都道府県が合いません」。5 桁以下・8 桁以上は要確認
- 電話番号：数字だけ。固定 10 桁／携帯 11 桁以外は要確認「電話番号の桁が違います」。空は要確認「電話番号なし」（行は残す・取込ファイルには出さない）
- クレカの生年月日 3 欄：`YYYY/MM/DD` に統一（convert_kureka と同じ。読めないときは元の値のまま要確認）

### 2-4 除外（④ §8-6 で決まった基準。026 の FileMaker 書き出し＋取込済み台帳の代わり）
- **過去に配った番号**＝Garden の **投入履歴**（`soil_list_assignment`）に同じ電話番号（クレカは電話番号・携帯番号の両方）があれば除外。表示：「過去に配った番号 n 件（リスト名・投入日つき）」
- **案件として既にある番号**＝Garden の **受注履歴**（`soil_list_order`。いまは顧客一覧から毎朝取り込み。取り込み元が全案件一覧に切り替わればそのまま効く）にあれば除外。表示：「案件あり n 件」
- 除外した行は取込ファイルに出さない。別シート「除外」に残す（026 の `FileMaker重複_除外_…` に相当）
- **同じアップロードの中の重複**：全列が同じ行は 1 件に（chatwork_report.py と同じ）。電話番号だけ同じで他が違う行は**消さず要確認「同じ番号が n 行」**（026 の確定ルール）
- 照会は電話番号の配列で `in` を 1,000 件ずつ（REST 8 秒・PostgREST 1,000 行の落とし穴）。50,000 行でも 1 分以内
