## 1. 入力欄（転送元・転送先の 2 か所とも同じ形）
```
転送元の住所（必須）
  郵便番号   [542-0081    ]   ← 数字 7 桁を入れたら住所を調べる（300ms 待ってから）
```

## 2. 保存の形（`address.ts` にまとめる・表示とテストで同じものを使う）
- 組み立て：`〒NNN-NNNN 住所 建物`。郵便番号が無ければ `住所 建物`、建物が無ければ最後のスペースは付けない。区切りは**半角スペース 1 つ**。
- そろえる（保存の前に 3 つの欄それぞれに）：
  - 全角の数字・英字 → 半角。全角スペース → 半角スペース。前後の空白を取り、続く空白は 1 つに。
  - **ハイフンのような記号（－ ‐ ― − ー ｰ など）は、数字と数字にはさまれているときだけ半角の「-」にする**。カタカナの長音（サンマリオンタワーの「ー」など）は変えない。例：「南船場２－１０－３０」→「南船場2-10-30」、「サンマリオンタワー」はそのまま。
  - 郵便番号は数字だけ取り出して 7 桁なら `NNN-NNNN`。〒や記号が付いていても受け付ける。
- 分解（今ある 1 行の住所を小窓で開くとき）：先頭の `〒?NNN-?NNNN` を郵便番号に。残りは**最初の半角スペースで**住所と建物に分ける（スペースが無ければ全部住所）。分けたものを組み立て直すと元と同じになること（今ある NLC の行で確かめる：`〒542-0081 大阪府大阪市中央区南船場2-10-30 NLC心斎橋アースビル503`・`〒541-0054 大阪府大阪市中央区南本町2-6-12 サンマリオンタワー地上2階西号室`）。
- データの持ち方（`from_address`・`to_address` の 1 行の文字）は変えない。migration は無し。一覧の表も今のまま。
