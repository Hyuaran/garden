交通費の支払い方が、給与の区分で違う。

```
　月給（社員）　　… 定期代を毎月まとめて支給する
　時間給（アルバイト）… 往復交通費 × 出勤日数 で支給する
```

いまの画面は、区分にかかわらず**月額の支給額**を出している。
アルバイトの方に月額の支給額が入ると、**毎月その額を払う指示に読めてしまう。**

**上限で頭打ちにする計算は、給与計算（④給与）側に入れる。今回は入れない。**
入社手続きは**事実を記録するだけ**にする。

**新しい列は作らない。SQLも不要。**

## 1. 画面の絵

### 給与の区分が「月給」または未選択のとき（いまのまま）

```
　　本人の申告（1か月定期代）   20,000円
　　本人の申告（片道）         530円
　　交通費の上限（1か月・円）   [ 15,000        ]
　　支給額（1か月・円）        [ 15,000        ]
　　                          上限以下なら申告額、超えたら上限
　　1日あたり（往復・円）       1,060円
　　                          欠勤などで数日だけ出た月と、アルバイトの方は この額 × 出勤日数
```

### 給与の区分が「時間給」のとき（新しい見え方）

```
　　本人の申告（1か月定期代）   20,000円
　　本人の申告（片道）         530円
　　交通費の上限（1か月・円）   [ 15,000        ]
　　1日あたり（往復・円）       1,060円
　　                          この額 × 出勤日数 で支給します
```

- **「支給額（1か月・円）」の欄そのものを出さない**
- **交通費の上限は出す**（給与計算で頭打ちに使うため）
- 1日あたりの下の文を **「この額 × 出勤日数 で支給します」** に差し替える
  （月給・未選択のときは今までの文のまま）

### 区分を切り替えたとき

- **「時間給」に変えたら、月額の支給額を空にする**（画面と保存の両方）
  月額を払う指示が残らないようにするため
- 「月給」に戻したら、いまの決め方（上限以下なら申告額、超えたら上限）で入れ直す
- 事務が支給額を手で書き換えたあとは自動で入れ直さない、という今の決まりは**そのまま**

## 2. 入社連絡表

連絡表には**定期代の欄（`commute_pass`／G45）と往復の欄（`commute_round`／G46）が既にある**。
区分で使い分ける。

| 給与の区分 | 定期代の欄 | 往復の欄 |
|---|---|---|
| 月給・未選択 | 15,000（今のまま） | 空 |
| **時間給** | **空** | **1,060** |

いまは「定期代が空のときだけ往復を出す」作りになっている。
**これを「区分で決める」に変える。**

- 時間給のときは、月額の支給額が入っていても**定期代の欄には出さない**
- 往復の額は `commuteTotals(...).fareOneway × 2`（Codex-284 と同じ出し方）
- 片道が入っていない人は、どちらの欄も空

Excel・PDF の**両方**で同じにする。
