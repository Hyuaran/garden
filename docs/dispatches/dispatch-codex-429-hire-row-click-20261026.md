# Codex-429：入社予定者の表を「行を押すと修正」に・操作は［辞退］［入社］・検索の案内文（2026-10-26）

## 目的（東海林さん 2026-10-26）
- 操作のボタンは「辞退」「入社」にしたい。ボタンの間隔は空ける。
- 修正は、口座残高の画面のように**行のどこに触っても 1 行に触っている感じ**にして、クリックで修正のモーダルが出るようにする（［修正］ボタンは消す）。
- 検索窓の「内容・金額」がこの画面では合っていない。

## 画面の絵
```
入社予定者 タブ
┌ 入社予定日 ⌄ ↑ │ 氏名 ⌄ ↕ │ 雇用形態 ⌄ ↕ │ 状態 ⌄ ↕ │ 操作 ┐
│ 2026-10-27     │ 足立 真美 │ 正社員       │ 入社予定 │ [辞退]   [入社] │ ← 行全体にマウスを乗せると行の背景が薄く変わる・指のカーソル
└──────────────────────────────────────────────┘    行を押す（ボタン以外）＝修正のモーダル
検索 ┌ 🔍 氏名・カナで探す ┐
```
- ［入社］＝今の［出社を確認して入社にする］と同じ動き（確認のモーダル→登録）。途中で止まった人は今の［続きから］のまま（文言はそのまま）。
- ［辞退］＝今の［来なかった］と同じ動き。状態の表示も「来なかった」→「辞退」、「来なかった人も表示」→「辞退した人も表示」（localStorage のキーは今のままでよい）。DB の値は変えない（表示の文言だけ）。
- ボタンの間は 12px 以上。［辞退］は赤の線のボタン、［入社］はティールの塗り（正本 §2.5「ボタン」）。高さはそろえる。
- 修正のモーダル＝今の登録フォーム（Codex-428 後の形）をモーダルで出す。見出し「入社予定者を修正」・［保存する］［閉じる］・Esc と外を押すと閉じる・スマホではみ出さない。［＋ 入社予定者を登録］も同じモーダルで出す（ページの下に出すのをやめる）。
- 行を押して開けるのは状態が「入社予定」の行だけ（入社処理の途中・辞退の行は押せない＝カーソルも普通）。

## やること
1. `src/app/system/_components/DataTable/DataTable.tsx` に 2 つ足す（他の画面の見た目は変えない・既定値は今の動き）。
   - `searchPlaceholder?: string`（既定は今の「内容・金額」）。
   - `onRowClick?: (row: T) => void` と `rowClickable?: (row: T) => boolean`：押せる行は `cursor:pointer`・マウスを乗せると行全体の背景（`--hover` が無ければ `color-mix(in srgb, var(--teal) 8%, transparent)`）。行の中のボタン・リンク・入力を押したときは発火しない。キーボード：行に `tabIndex=0`・Enter／Space で開く・フォーカスの枠を出す。
   - 見本の触り心地＝`src/app/bud/bank/bank.module.css` の `.matrix td:has(.stretchLink)`（ここは読むだけ・変えない）。
2. `src/app/system/onboarding/HireCandidatesClient.tsx`（＋`onboarding.module.css`）：上の絵のとおり。入社予定者タブの検索は `searchPlaceholder="氏名・カナで探す"`、入社後の確認タブも同じ、入社手続きタブは今のまま。
3. テスト：行を押すとモーダルが出る／ボタンを押しても行のモーダルは出ない／辞退・入社の文言／Esc で閉じる。
