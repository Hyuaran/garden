## 0. 何を作るか

Excel「【月1】給与計算用」シート（42 種類の式・752 セル）を Garden の **「給与試算」** タブとして計算する。人ごとに 1 行（並びはアポランのランキング順）で、アポラン・実績管理・従業員台帳（交通費）から引いた値と、東海林さんの手入力 7 項目から、次月時給・APインセン・社長賞・件数賞・支給合計・所定時間・勤務日数・交通費を出す。**この表は給与の材料（試算）。本物の給与計算は Bud**。名前は画面でも「給与試算」（「給与計算用」は使わない）。現場には出さない。

### 既知の差分（Excel の癖。Garden は正しい値で進める＝これまでの東海林さん決定と同じ。1 の内訳は東海林さんの回答（2026-09-07）で確定）
1. **支給合計 W＝SUM(O24:T24)**：基本・APインセン・**研修時間（時間の数がそのまま円として足されている）**・社長賞・件数賞・入社祝い金 の合計で、人材紹介インセン（U）と案件インセン（V）が入っていない。例：竹上 8 月は研修時間 2 が 2 円として入っている（204,752 円）。研修時間ぶんの賃金（×1,500 円）もどこにも無い。Garden は **基本＋APインセン＋研修手当（研修時間×1,500）＋社長賞＋件数賞＋入社祝い金＋人材紹介インセン＋案件インセン** で出す（東海林さん 2026-09-07：研修時間＝入社後 120h はアルバイトの成績に関わらず時給 1,500 円）。golden の W は補正して比べる（8 月は研修時間 竹上 2h → +3,000 円、研修時間の 2 円は除く）
2. 上の枠（行 3〜19 のチーム別サマリ）は参照がずれている（「テレマ全体」の列にアポランの宮永の値、1部小泉・2部宮永の列は 0 や −80）。Garden の給与試算タブでは **この枠は作らず**、インセ計算タブとアポランタブに任せる。golden の比較対象にしない
3. 社員（時給が文字）の行は Excel が #VALUE!（J・K・P・W）。Garden は null＝「—」。golden は null で一致とみなす
