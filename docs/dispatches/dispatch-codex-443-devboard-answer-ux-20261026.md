## 1. 進捗バーの数え方（東海林さん OK 済み）
今は完了も含めて「残り 3件（全7件）」。完了がたまるとバーが長くなり残りが見えなくなる。
- バーで数えるのは**まだ終わっていない質問だけ**（未回答＋回答済み＋Claude が対応中）。完了は数えない（「完了（○件）」の折りたたみにだけ残す）。
- 色：**灰色＝未回答（東海林さんの番）**／**ティール＝回答済み・対応中（Claude の番）**。並びはティール→灰色。
- 文言：「**残り 3件（回答待ち）・対応中 1件**」（数字は太字）。回答待ち 0 なら「回答待ちなし・対応中 1件」、どちらも 0 なら「すべて完了しています」。30 件を超えたら 1 本の線（今のまま）。
```

━━━━ ━━━━ ━━━━ ━━━━     ← ティール1・灰色3
```

## 2. 選択肢以外でも答えられる（東海林さん「選択肢以外の回答ができないのでは？」）
- 選ぶ質問の選択肢の最後に、自動で「**その他（補足に書く）**」を足す（DB の options は変えず画面で足す。保存は answer_choice='other'）。
- **選択肢を選ばなくても、補足に文があれば［回答する］を押せる**（今は選ばないと押せない）。選択も補足も空なら押せない。
- 「その他」を選んで補足が空なら「補足に書いてください」と出す。

## 3. 一度選ぶと外せない（「ラジオボタンだと、一度クリックしたら消えない」）

- 選んでいるときだけ、選択肢の下に小さく［選択を外す］（線のボタン・小）。
