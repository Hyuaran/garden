## 3. PDFの中身（見本＝ver.2・固定文は§8）

- A4・**3ページ固定**（4ページ目を作らない）。pageNo「1」「2」「3」
- **全ページ左上に会社名のランニングヘッダ**（薄いグレー・見本と同じ。§8の1行目より上）
- ページ割りは見本と同じ:
  - p1: 改定日行→タイトル→〔雇用契約書〕パート→署名ブロック→〔労働条件通知書〕見出し＋会社住所ブロック→表（契約期間〜試用期間）
  - p2: 表（就業場所〜賃金 6.(ア)あたりまで）
  - p3: 表の残り（賃金の続き〜その他）＋「以下、余白とする。」
  - 表のページまたぎは**行を2つに分けて**表現（続き側のラベル列は空欄）。文の途中で不自然に切れる場合は
    またぎ位置を前後の項目境界に寄せてよい。見本の本文充填率（p1=88% p2=88% p3=49%）を目安に
- 表は View の border で再現（ラベル列＋内容列の2列。始業終業セル内の**シフト表（シフト/始業/就業/休憩時間×A/B/C行）も罫線つきで再現**）
- 差し込み・チェック:
  - タイトル「労働条件通知書 兼 雇用契約書（ □新規 □更新 ）」→ 選択区分に ✓
  - 乙欄 `[ 氏名 ]`（ブラケット内に従業員名を印字）
  - 署名ブロック: 通知日及び締結日=フォーム値印字 / 住所=フォーム値（**空なら下線だけの空欄**＝電子契約時に本人記入）/
    署名=氏名印字＋㊞は別要素で横並び（空枠のまま）
  - 会社住所ブロック: 1行目=〒部分・2行目=残りの住所・3行目=`{会社名}　代表取締役　{代表者名}　㊞`
    （address文字列の先頭「〒NNN-NNNN」トークンを1行目に。〒が無い形式なら全体を2行目に）
  - 表: 契約期間 `［開始日］ ～ ［終了日］`（YYYY年M月D日）/ 就業場所=フォーム値 /
    業務内容=選択肢に✓・「その他」選択時は `その他：［テキスト］` / 基本賃金 時給 `［N,NNN］円`（3桁カンマ）
- 誤字の扱い: 原本に「6か月ホに」「有休休暇」「法定越」の3か所の誤字があるが、**既定は原本通り転記**
  （§8がその正文）。東海林さんから修正指示が出た場合のみClaudeが§8を差し替える

## 5. テスト

- validate: 必須（従業員/区分/契約期間から・まで/業務内容/時給/締結日/就業場所）・
  「その他」選択時は jobTypeOther 必須・時給は正の整数・期間の前後関係
- PDF: 3ページ固定・折り返しハイフン0・行頭/行末禁則0（218のテストの流儀）・
  会社差し込み（COMP-001/003で会社名・代表者・住所が変わる）・区分✓・業務内容✓・空住所は下線のみ
- drive: ファイル名 `雇用契約書_YYYYMMDD.pdf`・人優先フォルダ・衝突時秒付き
- route: 発行→generated（Driveモック）・env未設定→skipped・生成失敗→failed・
  会社住所空→発行エラー（レコードを作らない）
- 既存の mypage / todoke / inbox テストが緑のまま

## 7. 発行フォームの入力項目（payload）

| 項目 | key | 型・既定値 |
|---|---|---|
| 従業員 | employee_id（列） | 在籍者（is_active）から選択。表示=社員番号・氏名・会社名・雇用形態 |
| 区分 | kind | "new"（新規）/ "renewal"（更新）ラジオ・必須 |
| 契約期間（から） | contractStart | date・必須 |
| 契約期間（まで） | contractEnd | date・必須（開始より後） |
| 業務内容 | jobType | "sales"営業職 / "office"事務職 / "tech"技術職 / "other"その他（単一選択・必須） |
| その他の内容 | jobTypeOther | text・jobType=other のとき必須 |
| 基本賃金（時給・円） | hourlyWage | 正の整数・必須 |
| 就業場所 | workLocation | text・必須（初期値=会社住所の〒抜き＋「（または甲が指定する場所）」） |
| 通知日及び締結日 | concludedOn | date・初期値=今日JST・必須 |
| 従業員住所 | employeeAddress | text・**任意**（空ならPDFは下線のみ） |
