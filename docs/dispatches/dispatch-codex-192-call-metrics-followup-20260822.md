## 1. 画面の「定義方法」タブだけ、見出しが左のまま

### 症状
`/system/call-metrics` の定義方法タブで、**2列目の見出しだけ左揃えのまま**。
実測（computed style）：

| 表 | 見出しの揃え |
|---|---|
| 集計の定義 | 指標=center ／ **定義=left** |
| 休憩時間割 | 回=center ／ **開始=left** ／ 終了=center ／ 長さ=center |
| コール履歴のフラグ名 → ポータル表示名 | コール履歴=center ／ **ポータル表示=left** |
| 結果フラグの扱い | 結果フラグ=center ／ **扱い=left** |

### 原因
`src/app/system/call-metrics/call-metrics.module.css` の43行目

```
.definitionTable th:nth-child(2), .definitionTable td:nth-child(2) { text-align: left; white-space: normal; }
```

`th`（見出し）にも `text-align: left` がかかっている。

### 直し方
**`th`（見出し）は中央揃えにし、`td`（中身）は左揃えのまま**にする。
`white-space: normal` は見出し・中身とも今までどおり効かせること（折り返しを止めない）。

**確認**：定義方法タブの4つの表すべてで、紺の見出しが中央・中身が左になっていること。

## 2. Chatwork配信の本文で、日付の前に空行が入る

### 症状
配信されたメッセージの `[info]` 枠の中で、**日付の上に1行分の空白**が入っている。

### 原因
`src/app/system/_lib/call-report.ts` の `buildCallReport`。
本文が `[/title]` の直後で改行しているため、Chatwork側で本文の1行目が空行になる。

```
[info][title]テレマ コール集計ポータル 自動配信[/title]
2026/08/22(土) 21:00
```

### 直し方
**`[/title]` の直後の改行をなくし、日付が本文の1行目に来るようにする。**

```
[info][title]テレマ コール集計ポータル 自動配信[/title]2026/08/22(土) 21:00
https://garden-os.net/system/call-metrics
...
```

- **日付より下の行（URL・【本日】以降）は今までどおり。**行を詰めたり増やしたりしない
- `call-report.test.ts` に本文の期待値があるはずなので、あわせて直すこと
- **コール0件のときスキップする動きは変えない**
