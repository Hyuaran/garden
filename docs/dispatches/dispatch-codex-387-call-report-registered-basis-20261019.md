**受注率の行と対象外率は、すべて「その日に Kintone に登録された記録（作成日時がその日＝日本時間）」で数える**（東海林さん「すべて『その日に Kintone に登録された記録のうち』どうか、という形にしてください」）
- 前確待ち＝その日に登録された記録のうち、対応状況が「前確待ち」
- 申込＝同じく「申込み」（今の `row.applications` と同じ）
- 受注＝前確待ち＋申込
- 受注率＝受注 ÷ その日に登録された記録（対応状況が「重複」のものは除く）。分母が 0 なら「-」
- 対象外率＝対象外（「対象外（現アナ等）」「対象外（契約不可）」「対象外（連絡つかず）」）÷ 同じ分母
- 発着信＝着信＋発信の合計を先に、内訳をかっこの中に
- 初回応答率の行は今の数え方のまま（応答・入電に「件」を付けるだけ）
- 対応状況の欄の名前はアプリごとに違う（`CUSTOMER_APP_CONFIG` の statusField）ので、それに合わせる
- Kintone が読めなかった事業（records が null）は今までどおり「-」
