## 0. これは何か

いまの経費の書き出しは**弥生会計に読ませるCSVだけ**。
これとは別に、**FileMakerの経費台帳と同じ22列の一覧**を書き出せるようにする。

2026-07-27 に一度だけ手作業で作って納品しており、**それをGardenの機能として内蔵する**のが今回。

## 1. 出す形

**Excel（.xlsx）・1シート・22列。**見本ファイルの並びとまったく同じ順にすること。

| # | 列名 | Gardenのどこから |
|---|---|---|
| 1 | 経理ID | **空欄**（§3参照） |
| 2 | 領収書No | **空欄**（§3参照） |
| 3 | 法人名 | 法人の略称（`bud_corporations.name_short`） |
| 4 | 使用者 | 申請者の氏名 |
| 5 | 適格区分 | `qualified_class`（有／無） |
| 6 | 適格番号 | `qualified_number` から**先頭の「T」を外した値**（§4） |
| 7 | 区分 | 経費区分の名称（`category_id` → 名称） |
| 8 | レシート日付 | `receipt_date` |
| 9 | 店名 | `store_name` |
| 10 | 金額 | `amount`（数値） |
| 11 | 入力日 | `submitted_at` の**日付** |
| 12 | 入力者 | `submitted_by` の氏名 |
| 13 | 入力時間 | `submitted_at` の**時刻** |
| 14 | 入力終了時間 | **空欄**（Gardenに無い） |
| 15 | 入力エラー項目 | **空欄**（Gardenに無い） |
| 16 | 確認日 | `keiri_checked_at` の**日付** |
| 17 | 確認者 | `keiri_checked_by` の氏名 |
| 18 | 確認時間 | `keiri_checked_at` の**時刻** |
| 19 | 確認終了時間 | **空欄**（Gardenに無い） |
| 20 | 仕分け日 | `journalized_at` の日付 |
| 21 | 仕分け法人名 | 法人の略称（3と同じ） |
| 22 | 決算区分 | 第N期（§5） |

- **日付と時刻は別の列に分ける**（見本と同じ。11と13、16と18、が同じ元の値から分かれる）
- 日付はExcelの日付として、時刻はExcelの時刻として書く（文字列にしない）
- 金額は数値。桁区切りの書式は付けても付けなくてよい
- **16〜18の「確認」は、経理の確認（`keiri_checked_*`）を使う。**
  Gardenには最終確認（`final_checked_*`）もあるが、FM台帳の「確認」は経理の確認にあたる。
  ※この対応づけは Claude の判断。完了報告に「経理確認を使った」と明記すること。

## 2. 画面（どこから出すか）

- 経費精算の画面に、**弥生CSVとは別のボタン**として置く。
  ボタン名は「**台帳形式で書き出す（Excel）**」。
- 弥生CSVのボタンの動きは**一切変えないこと**。
- **絞り込みは、いま画面で見えている条件（法人・期間など）に従う。**
  新しい絞り込みUIを増やさない。
- **★状態を変えないこと（一番大事）**
  弥生CSVの書き出しは、書き出すと同時に状態を「仕訳済み」に変える。
  **台帳形式の書き出しは、何の状態も変えない**。何度出しても中身が変わらない「控え」であること。
- 削除済み（`deleted_at` あり）は出さない。

---

## 3. 経理IDと領収書Noは空欄で出す

`accounting_id` と `receipt_no` は列としてDBにあるが、**どこからも書き込まれておらず全件空**。
これらは FileMaker 側で採番されてきた番号なので、**Gardenが勝手に振ると衝突する**。

→ **今回は空欄のまま出す。**空欄を埋める仕組みは作らない。

---

## 4. 適格番号は「T」を外す

- Garden は `T5120003009625` のように**T付き**で持っている
- FM台帳は `1000020272213` のように**Tなし**（13桁）で持っている

→ **台帳形式で書き出すときは、先頭が `T` または `t` なら1文字外す。**
それ以外はそのまま。空欄はそのまま空欄。
**DBの値は書き換えないこと**（書き出すときだけ外す）。

---

## 5. 決算区分（第N期）の出し方

`bud_corporations` の `established_on`（設立日）と `fiscal_end_month`（決算月）から計算する。

- 数える基準は**レシート日付**（`receipt_date`）。
- 設立日を含む期を**第1期**とし、決算月の末日で期が変わる。
- 例：設立が2018年3月・決算月が9月なら、2018年3月〜2018年9月末が第1期、
  2018年10月〜2019年9月末が第2期。
- `established_on` か `fiscal_end_month` が空の法人は、決算区分を**空欄**にする（推測しない）。

**★設立日・決算月はDBの値を使うこと。**Web検索で調べた法人情報には誤りがあるため使わない。

## 6. テスト

- 22列が**見本と同じ順・同じ列名**で出ること
- 日付列がExcelの日付、時刻列がExcelの時刻になっていること
- 適格番号：`T5120003009625` → `5120003009625` ／ Tなしはそのまま ／ 空欄は空欄
- 経理ID・領収書Noが空欄であること

- 決算区分：期の境目（決算月の末日とその翌日）でN期が変わること／設立日・決算月が空なら空欄
- 対象0件のときも、**見出しだけのファイルが出る**こと（エラーにしない）
