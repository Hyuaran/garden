## 2. 計算のルール（Excel の式から起こした。答えから係数を逆算しない）

### 2-1. チーム別ブロック（列 D〜H＝全体／宮永／小泉／石原／新人）
| 行 | 項目 | 式 |
|---|---|---|
| 5 | 実績P | 上の表のとおり |
| 8 | 稼働h | Σ 実績管理 H（department 一致） |
| 9 | 着地予想h | Σ 実績管理 G（department 一致） |
| 4 | 効率 | 実績P ÷ 稼働h（稼働h が 0 なら null＝Excel は #DIV/0!） |
| 6 | 目標P | 今月の設定 |
| 7 | 現時点必要P | ROUNDDOWN(（対象日の稼働日番号 ÷ 月の稼働日数）× 目標P, 1)。対象日が管理表の稼働日に無い（定休日・月をまたぐ）なら null（Excel は #N/A） |
| 11 | 達成率 | 実績P ÷ 現時点必要P（必要P が null／0 なら null） |
| 10 | 着地予想P | ROUNDDOWN(目標P × 達成率, 1)（達成率が null なら null） |

- 「対象日」＝run の target_date（Excel は TODAY()）。8/31 の golden は J18＝2026-09-01 なので 行 7・10・11 は null が正
- 例（単体テストに入れる）：8 月・対象日 2026-08-15（稼働日番号 13、月の稼働日数 27）・全体の実績P 260.6・目標P 240 → 現時点必要P＝ROUNDDOWN(13÷27×240,1)＝**115.5**、達成率＝260.6÷115.5＝2.2562…、着地予想P＝ROUNDDOWN(240×2.2562…,1)＝**541.5**
- ROUNDDOWN は小数第 1 位切り捨て（負にはならない）

### 2-2. ランキング（行 21〜48・28 人）
1. 元の並び（実績管理の順）で 1 人ずつ：部署＝実績管理 E（department）、氏名、時給＝実績管理 D（wageLabel：「社員」「派遣」の文字か数値）、獲得ポイント＝I（totalPoints）、稼働時間＝H（workHours）、効率＝J（efficiency・**未丸め**）、着地時間＝G（landingHours）、デジタル着地＝効率（未丸め）× 着地時間
2. **ステータス**（時給から）：「社員」→社員、「派遣」→派遣、2000 以上→ブラック、1800 以上→ダイヤモンド、1600 以上→プラチナ、1400 以上→ゴールド、1200 より大きい→シルバー、それ以外（1200 以下）→ null（Excel は #N/A）。設定表を作らず、この段階（しきい値の表）を 1 か所の定義に置く
3. **順位**：獲得ポイントの多い順（RANK.EQ）。同点は元の並びが上の人が先（Excel は 順位＋行番号÷100 で並べている。同じ結果になればよい）
4. 表示は順位順。効率の表示は **小数第 2 位切り捨て**（ROUNDDOWN 2）だが、デジタル着地は未丸めの効率で計算する
5. 人数は 28 に決め打ちしない（人設定の在籍者ぶん）
