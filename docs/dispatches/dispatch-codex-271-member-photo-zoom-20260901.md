## 1. やること

会社説明の「共に働く仲間」の顔写真を、**クリックすると大きく表示**できるようにする。

### いまの画面

```
　共に働く仲間
　┌───────────┐  ┌───────────┐  ┌───────────┐
　│   （顔写真）   │  │   （顔写真）   │  │  （イニシャル） │
```

### 写真をクリックしたあと

```
　┌──────────────────────────────────┐
　│  画面全体をおおう暗い幕                        [ × ] │
　│                                            │
　│              ┌──────────────┐              │
　│              │                │              │
　│              │   大きい顔写真   │              │
　│              │                │              │
　│              └──────────────┘              │
　│                   後道 翔太                    │
　│                                            │
　└──────────────────────────────────┘
　　閉じ方は3つ：右上の × ／ 幕（写真の外）をクリック ／ Esc キー
```

## 2. 決まりごと

- **画面の中に出す。ブラウザ標準の窓（`window.open` など）は使わない**
- 写真は画面に収まる大きさまで拡大する（`max-width:90vw` `max-height:80vh` 目安）。**縦横の比は変えない**
- 幕の下に**名前**を出す。役職は出さなくてよい
- 閉じるボタンは **絵文字を使わない**。既存の組織図やヘッダーと同じ **SVGの線画** で × を描く
- **写真が無い人（イニシャルの丸が出ている人）はクリックしても何も起きない**。押せる見た目にもしない
- 写真がある人のカードは、キーボードの Tab で移動でき、Enter / Space でも開けること（`button` 要素にする）
- 開いている間は後ろの画面をスクロールさせない
- **ライト／ダークのどちらでも、幕・写真・名前・×が見えること**。色は `docs.module.css` の既存の変数を使う
- **オリエンテーション表示（`/system/docs/company/present`）でも同じように動くこと**
