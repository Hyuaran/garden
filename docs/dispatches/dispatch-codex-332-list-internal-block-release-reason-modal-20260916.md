## 0. 何を直すか（東海林さん 2026-09-16「今日」）

自社アポ禁の登録済み一覧で［解除］を押すと、いまは**ブラウザ標準の小窓**（window.prompt）が開く。見た目が Garden と違い、Chrome の自動操作で固まることもある。これを**社長スタイルの入力モーダル**に置き換える。それ以外の動き（API・一覧の更新・メッセージ）は変えない。

## 1. 画面

```
［解除］を押す →

┌ 自社アポ禁を解除する ────────────────────────────────┐
│ 電話番号  0285720215                                     │
│ 登録日    2026-09-15（月）   理由  重クレーム   登録者 東海林 │
│                                                          │
│ 解除理由（必須）                                          │
│ ┌────────────────────────────────────────────────┐ │
│ │                                                    │ │
│ └────────────────────────────────────────────────┘ │
│ 例：本人から再架電の了承あり／登録間違い                    │
│                                                          │
│                              [ やめる ]  [ 解除する ]     │
└──────────────────────────────────────────────────────┘
```

- 上段は対象行の値（電話番号・登録日・理由・登録者）を読むだけで出す
- 解除理由は複数行の入力欄（textarea・2 行分の高さ）。空のまま［解除する］は押せない（disabled）。前後の空白は落として送る
- ［解除する］→ 送信中は「解除中…」で二重押し防止 → 成功でモーダルを閉じ、一覧を再読込、今までどおり「解除しました」のメッセージ。失敗はモーダル内に赤字で理由（API の error をそのまま）。Esc／背景クリック／［やめる］で閉じる（送信中は閉じない）
- 見た目は「条件を保存」モーダルと同じ部品・同じ余白・同じボタン（濃紺の主ボタン＝解除する／白の副ボタン＝やめる）。絵文字なし
- `window.prompt`・`window.confirm` はこのファイルから無くす（grep で 0 件にする）
