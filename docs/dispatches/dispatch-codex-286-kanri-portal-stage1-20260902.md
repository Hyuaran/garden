### 4-5. 注意（warnings）の判定 — 今回はこの4つだけ

| code | いつ出すか | 画面の文 |

## 6. 取り込みの API

- POST /api/system/kanri/runs … body { targetDate: "YYYY-MM-DD", mode: "daily"|"closing" }
  → run を作り、**その場で取得まで行って**結果を返す（時間がかかるので maxDuration = 120）
  → 戻り { ok, runId, status, summary, warnings }
- GET /api/system/kanri/runs?limit=10 … 直近の取り込み一覧
- GET /api/system/kanri/runs/[id] … 1件の詳細（summary・warnings。**payload は返さない**）
- GET/PUT /api/system/kanri/month-settings/[yearMonth] … 定休日の読み書き
- どれも manager 以上。書き込みは getSupabaseAdmin()（service_role）で行う

同じ対象日で何度取り込んでもよい（毎回新しい run）。古い run の生データは残す（監査・再生成用）。
