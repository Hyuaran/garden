## 1. 画面の絵

置き場所は **「本人が入れた内容」→「住所と連絡先」→ 電話番号のすぐ下**。
給与や保険の「事務が入れる」ではなく、**連絡先のところに置く**（そこが探しに行く場所のため）。

```
　本人が入れた内容                       ← 見出しから「（読むだけ）」を外す
　　…
　　住所と連絡先
　　　郵便番号        6360001
　　　住所           奈良県北葛城郡王寺町舟戸1-1-25
　　　住所のフリガナ    ナラケンキタカツラギグンオウジチョウフナト
　　　電話番号        090-5467-7653
　　　メールアドレス    hy.09054677653@docomo.ne.jp        [ 修正 ]
　　　　　　　　　　　 事務が入れられます
```

**【修正】を押すと、その行だけ入力できるようになる。**

```
　　　メールアドレス    [ hy.09054677653@docomo.ne.jp     ]  [ 保存 ] [ やめる ]
　　　　　　　　　　　 事務が入れられます
```

- ふだんは**読むだけ**の見た目。【修正】を押して初めて入力できる
- 【保存】でメールアドレスだけを保存する。保存できたら読むだけの見た目に戻り、
  その場に **「保存しました」** と出す
- 【やめる】で、押す前の値に戻して読むだけの見た目に戻す
- 保存に失敗したら、その場に日本語で理由を出す（読むだけには戻さない）
- ほかの行は今までどおり読むだけ。**【修正】が出るのはメールアドレスの行だけ**
- 行の下に小さく **「事務が入れられます」** と添える
- 【保存】は**この行のためのボタン**。下の「事務が入れる」の【保存】とは別（あちらは触らない）
- **ブラウザ標準の窓は使わない**
- 絵文字を使わない

### 見出しの変更

いまの `本人が入れた内容（読むだけ）` を **`本人が入れた内容`** に変える。
1か所だけ入力できるようになるため、「読むだけ」は実態と合わない。

## 2. 決まりごと

- **責任者以上だけ**が入れられる（事務の画面と同じ判定。API側でも必ず確認する）
- 形が明らかにおかしいときだけ、その場に注意を出す
  （`@` が無い／2つ以上／空白が入っている → 「メールアドレスの形になっていません」）。
  **入力も保存も止めない**。本人画面と同じ判定を使い回す
- **空にして保存できる**（間違えて入れたときに消せるように）
- 保存したら画面の表示も新しい値に変わる
- 保存の入り口は既存の `POST /api/system/onboarding/admin/<社員番号>` に
  `action: "email"` を足す形にする。**新しいAPIの置き場所を増やさない**
- メールアドレス以外の本人入力項目は**サーバー側で受け取らない**
  （`action: "email"` のときは `email` だけを保存する）
