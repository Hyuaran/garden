## 1. やること

人の行（グループ見出し）の金額に、**税抜の金額をカッコ書きで併記**する。

**いま**
```
選択 2件 ¥13,740 ／ 全25件 ¥205,043
```

**こうする**
```
選択 2件 ¥13,740（¥12,490） ／ 全25件 ¥205,043（¥186,402）
```

### 計算のしかた
- **表示している金額 ÷ 1.1**
- **小数点以下は切り捨て**（四捨五入しない）
- 検算：`13,740 ÷ 1.1 = 12,490.909… → 12,490` ／ `205,043 ÷ 1.1 = 186,402.727… → 186,402`
- **合計してから割る**（1件ずつ割って足すのではない）。上の検算はその前提の数字
- 0円のときは `¥0（¥0）`

---

## 2. 変えないこと

- カッコの外の金額（税込）はいままでどおり
- 上部カード（総額・選択した額）は**今回は変えない**
- 明細1行ずつの金額表示も変えない
- 人・明細の並び順、要確認の表示、まとめて選ぶ動き
- 弥生CSV・台帳形式Excel・法人絞り込み・statusの意味
- **DBの値は一切変えない**（表示のときに割るだけ）

---

## 3. テスト

- `¥13,740` → `¥13,740（¥12,490）`、`¥205,043` → `¥205,043（¥186,402）` になること
- 切り捨てであること（四捨五入だと 12,491 / 186,403 になる。そうならないこと）
- 0円が `¥0（¥0）` になること
- 選択を変えると、カッコの中の数字も一緒に変わること
- **文字が幅からはみ出さないこと**（狭い幅では折り返す。Codex-197 でカードが切れた失敗の再発防止）
