## 1. 申請者ドロップダウン

仕訳待ちタブ（`ExpenseBookingPanel.tsx`）にも付ける。

- 形式：選択式（ドロップダウン）。**いまその一覧に居る申請者だけ**を選択肢に出す（全社員名簿を出さない）
- 「全員」が既定。絞ると一覧がその人のまとまりだけになる
- 名簿にいない申請者（`applicant_name_text` だけの人＝FM取込分）も選択肢に出ること
- 既存の共通関数をそのまま使う：
  `C:\garden\a-bloom-008\src\app\bud\expenses\_lib\expense-final-applicant-filter.ts`
  （`buildFinalApplicantOptions` / `filterFinalRowsByApplicant`。型は汎用なので仕訳待ちの行でも使える）
- 置き場所：既存の「元法人（選択先）」の並びに置く

## 2. 検索欄（名前を打っても絞れるように）

完了待ちタブと同じ「項目セレクタ＋検索欄」を仕訳待ちにも付ける。

- 共通の検索ロジック（完了待ちが使っている `filterExpenseListRecords` 系）を流用する
- 項目は**仕訳待ちの一覧に出ている列に合わせる**：
  全項目／申請者／日付／仕分け日／仕分け法人名／決算区分／区分（経費区分）／店名／金額
  （画面に無い項目は入れない。逆に画面に出ている列は検索できるように）
- 「全項目」検索に**申請者名が含まれる**こと（名前を打つだけで人を絞れるのが今回の主目的）
- プレースホルダは「仕訳待ちを検索」

## 3. 絞り込み・検索と他の機能の関係（重要）

- **全選択・「仕分け情報を入力」・「選択を削除」・件数表示は、絞り込み／検索後の行だけに効く**こと
  （見えていないものを巻き込まない。完了待ち #462 と同じ考え方）
- 人ごとのまとまり（グループバー・#452〜454）と、バーのスクロール固定（#461）は壊さない
- 絞った状態でもグループバーの「選択 n件 ¥…／全n件 ¥…」の数字が絞り後の実態と合うこと
- 「台帳形式で書き出す（Excel）」は現状の対象範囲の考え方を変えない
  （もし現状が「選択した行」基準なら、絞り込みで選択が変わる分だけ自然に連動する。仕様を変えない）

## 4. 変えないこと

- status の値・遷移、仕分け情報入力の処理そのもの
- 元法人フィルタ（sessionStorage 記憶）の挙動
- 会社経費バッジ・処理中オーバーレイ（#462）
- 完了待ちタブ側は一切触らない
- 新しいライブラリを増やさない

## 5. テスト

- 申請者で絞ると一覧・件数がその人だけになること／「全員」で戻ること
- 名簿にいない申請者（氏名テキスト）も選択肢に出て絞れること
- 検索欄に名前を打つと絞れること（全項目・申請者の両方）
- 仕分け日・仕分け法人名・決算区分でも検索できること
- 絞り込み中の全選択・仕分け情報入力・選択削除が、絞った行だけに効くこと
- グループバーの選択件数・金額が絞り後で正しいこと
- 文字が幅からはみ出さないこと
