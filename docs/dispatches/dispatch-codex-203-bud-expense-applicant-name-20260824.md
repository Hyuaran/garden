# Codex-203 経費に「申請者の氏名（文字）」を持てるようにする（過去データ取り込みの下準備）

- 発行日: 2026-08-24
- 対象画面: Bud 経費精算（`/bud/expenses`）
- 作業ツリー: `C:\garden\a-bloom-008`（`main f47dead` 起点）

---

## 0. 何のためか

FileMaker時代の経費 **12,714件** を Garden に取り込む（取り込み自体は Claude がスクリプトで行う。**このDispatchの範囲外**）。

その中に、**Gardenの社員名簿に存在しない使用者**が9名・3,531件ある
（退職済みの方と、個人ではない「会社」名義）。社員名簿には登録しない方針のため、
**経費の行そのものに氏名の文字を持たせ、名簿に居ない人でも名前が表示される**ようにする。

---

## 1. データの持ち方

`bud_expense_requests` に1列足す（migration の SQL を置くところまで。**本番適用はしない**）。

| 列 | 内容 |
|---|---|
| `applicant_name_text` | 申請者の氏名（文字）。**社員名簿とつながらない行のためのもの** |

- 既存の `applicant_employee_id`（名簿とつながる行）は今までどおり。**両方入っている場合は名簿を優先**
- Gardenの画面から申請する通常の流れでは**この列に書き込まない**（今までどおり名簿のIDだけ）

---

## 2. 表示の直し方

**申請者名を出しているすべての場所**で、次の順で名前を決める共通の関数を作って使うこと：

1. `applicant_employee_id` が名簿とつながる → 名簿の氏名（いままでどおり）
2. つながらない・空で、`applicant_name_text` がある → **その文字**
3. どちらも無い → 「未設定」（いままでどおり）

直す場所（洗い出してすべて。少なくとも以下）：
- 仕訳待ちタブ（人ごとのまとまりの見出し・明細行）
- 完了タブ（申請者列）
- 一覧タブ・削除済みタブ（申請者を出していれば）
- **台帳形式Excel**（4列目「使用者」）
- **弥生CSV**（摘要等に申請者名を使っていれば）

### 人ごとのまとまり（仕訳待ちタブ）
- `applicant_name_text` だけの行も、**その名前でまとまる**こと（「未設定」に混ざらない）
- 並びは今までどおり氏名順。名簿の人と文字だけの人が混ざっても、同じ氏名順に並ぶ

---

## 3. 変えないこと

- Gardenからの通常の申請の流れ（この列には書き込まない）
- `status` の値・意味
- 弥生CSV・台帳形式Excelの形式（名前の出どころが増えるだけ）
- 出力履歴（Codex-202）・仕分け情報（Codex-200）
- 新しいライブラリを増やさない

---

## 4. テスト

- 名簿とつながる行 → 名簿の氏名（回帰）
- `applicant_name_text` だけの行 → その文字が、仕訳待ち・完了・台帳Excelで出ること
- 両方ある行 → 名簿を優先
- どちらも無い行 → 「未設定」
- 文字だけの行が人ごとのまとまりで**自分の名前のまとまり**になること（未設定に混ざらない）
- **文字が幅からはみ出さないこと**
